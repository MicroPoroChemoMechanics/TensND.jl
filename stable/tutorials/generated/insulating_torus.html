An insulating torus in a uniform flux ​

See also

Theory: Toroidal coordinates · Toroidal functions · Curvilinear differential calculus

Manual: Coordinate systems (symbolic) · Charts and coordinate conversions · Toroidal functions

A ring-shaped pore in a conducting medium, under a remote temperature gradient along its axis: the temperature is harmonic outside the pore and its flux does not cross the surface. The toroidal chart turns the surface of the pore into a coordinate surface, and the problem into a tridiagonal system on the amplitudes of a series of toroidal functions. This tutorial sets it up and solves it with the chart and the functions of the package, checks the result by automatic differentiation, and draws the cases of (Radi and Sevostianov, 2016): the temperature around a torus of ratio   and the temperature on its surface for several ratios.

The remote field as a series ​

A function harmonic in the medium and bounded on the axis is a series of the products  , where is the toroidal function of the first kind (Separation of the Laplace equation). The remote field of a unit gradient along the axis has the series, of the second kind,

julia
s(n) = 4 * sqrt(2) / π * n
function x₃_series(α, β; N = 60)
    Q = toroidal_Q(N, 0, α)
    return a * sqrt(cosh(α) - cos(β)) * sum(s(n) * Q[n + 1] * sin(n * β) for n in 1:N)
end

julia
function amplitudes(α₀; N = 40)
    P, dP = toroidal_P(N + 1, 0, α₀), toroidal_dP(N + 1, 0, α₀)
    Q, dQ = toroidal_Q(N + 1, 0, α₀), toroidal_dQ(N + 1, 0, α₀)
    ℓ = dP ./ P                                                 ## ℓ[n + 1] is ℓₙ
    diagonal = [sinh(α₀) + 2 * cosh(α₀) * ℓ[n + 1] for n in 1:N]
    lower = [-ℓ[n] for n in 2:N]                                ## the factor of xₙ₋₁ in the relation n
    upper = [-ℓ[n + 2] for n in 1:(N - 1)]                      ## the factor of xₙ₊₁
    right = [-(s(n) * (sinh(α₀) * Q[n + 1] + 2 * cosh(α₀) * dQ[n + 1]) - s(n - 1) * dQ[n] - s(n + 1) * dQ[n + 2]) for n in 1:N]
    return (Tridiagonal(lower, diagonal, upper) \ right) ./ P[2:(N + 1)]
end

The amplitudes decay as . The temperature at a point is the remote field plus the series of the perturbation; cartesian_to_coords gives the coordinates of the point in the chart.

julia
function temperature(chart, b, x)
    _, α, β = cartesian_to_coords(chart, x)
    P = toroidal_P(length(b), 0, α)
    return x[3] + chart.a * sqrt(cosh(α) - cos(β)) * sum(b[n] * P[n + 1] * sin(n * β) for n in eachindex(b))
end
T(x) = temperature(chart, b, x)
T([1.8, 0.3, 0.4])
0.49496582483707835

Checks by automatic differentiation ​

The function is differentiated through the chart and the toroidal functions. Its Laplacian vanishes in the medium, and its derivative along the normal vanishes on the torus, here at a few points:

julia
laplacian_at(x) = tr(ForwardDiff.hessian(T, x))
function normal_flux_at(φ, β)
    x = coords_to_cartesian(chart, (φ, α₀, β))
    ν = ForwardDiff.derivative(α -> coords_to_cartesian(chart, (φ, α, β)), α₀)      ## along 𝐞ᵅ, normal to the torus
    return dot(ForwardDiff.gradient(T, Vector(x)), ν / norm(ν))
end
maximum(abs, laplacian_at.([[1.8, 0.3, 0.4], [0.2, -0.1, 0.9], [0.1, 0.0, -0.2]])),
    maximum(abs, normal_flux_at(φ, β) for φ in (0.0, 1.0), β in (0.3, 1.5, 2.9))
(8.881784197001252e-16, 4.996003610813204e-16)

The temperature on the torus ​

On the surface the temperature is drawn against the angle around the tube, from the point farthest from the axis, for three ratios . Without the pore it would be ; around a thin ring it tends to , the temperature on an insulating cylinder across the gradient, and it loses its symmetry about   as the hole of the torus closes.

julia
plot(; xlabel = "θ", ylabel = "T / (G r)", legend = :topright, size = (640, 380))
for ratio in (0.25, 0.5, 0.75)
    torus = ToroidalChart(1.0, ratio)
    amplitude = amplitudes(acosh(1 / ratio); N = 80)
    on_surface(θ) = temperature(torus, amplitude, [1 + 1.000001 * ratio * cos(θ), 0.0, 1.000001 * ratio * sin(θ)]) / ratio
