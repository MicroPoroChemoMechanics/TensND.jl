Thomsen's parameters and weak anisotropy ​

See also

Theory: Plane waves · Thomsen's parameters

Manual: Plane waves

Tutorials: Weak anisotropy of any symmetry · Stress-induced anisotropy

A transversely isotropic medium has five elastic constants. Thomsen (1986) replaces them by the two velocities along the axis, and , and three dimensionless numbers , and that vanish for an isotropic medium and are small for most rocks. This tutorial builds media from the parameters of his Table 1, compares their exact velocities with the first-order ones, recovers the first-order formulas from the exact ones with symbols, and shows why governs the directions close to the axis.

using LinearAlgebra

Notes

  • The article defines delta_star and delta from the same five moduli, so that delta_star = (1 - V_S0^2/V_P0^2)(2 delta - epsilon) holds exactly. For the four crystals quartz, calcite, biotite and ice of this selection the printed delta_star and delta do not satisfy this relation to the printed digits; the values are kept as printed.
  • The densities of the Pierre shale rows are printed with a question mark and the row 'shale (5000)' is struck through on the scan; neither is transcribed.

With the velocities in km/s and the density in g/cm³, the stiffness comes in GPa. ti_from_constants(V_P0, V_S0, ε, δ, γ, axis; form = :thomsen, density = ρ) returns the transversely isotropic stiffness of axis :

julia
e₃ = [0.0, 0.0, 1.0]
function medium(r)
    ρ = r["rho (g/cm3)"]
    ℂ = ti_from_constants(r["V_P0 (m/s)"] / 1000, r["V_S0 (m/s)"] / 1000, r["epsilon"], r["delta"], r["gamma"], e₃; form = :thomsen, density = ρ)
    return ℂ, ρ
end
table_row(name) = only(filter(r -> r["sample"] == name, rows))

Exact and first-order velocities ​

Along a direction at the angle to the axis, the three waves are a quasi-longitudinal one (qP), a quasi-transverse one polarized in the plane of and the axis (qSV), and a transverse one normal to that plane (SH). wave_modes gives their exact velocities, weak_wave_modes the first-order ones

julia
θs = range(0, π / 2; length = 91)
modes = (:qP, :qSV, :SH)
exact_velocity(ℂ, ρ, θ, k) = wave_modes(ℂ, ρ, direction_from_angles(θ, 0.0))[k][1]
weak_velocity(ℂ, ρ, θ, k) = weak_wave_modes(ℂ, ρ, direction_from_angles(θ, 0.0))[k]

function velocity_panel(name)
    ℂ, ρ = medium(table_row(name))
    V = [exact_velocity(ℂ, ρ, θ, k) for θ in θs, k in modes]
    W = [weak_velocity(ℂ, ρ, θ, k) for θ in θs, k in modes]
    p = plot(; title = name, titlefontsize = 10, xlabel = "angle to the axis θ (°)", ylabel = "phase velocity (km/s)", xticks = 0:15:90, legend = :right)
    plot!(p, rad2deg.(θs), V; lw = 2, color = [1 2 3], label = ["qP" "qSV" "SH"])
    plot!(p, rad2deg.(θs), W; lw = 2, ls = :dash, color = [1 2 3], label = ["first order" "" ""])
    return p
end
plot(velocity_panel(weak_rock), velocity_panel(strong_rock); layout = (1, 2), size = (980, 380), left_margin = 4Plots.mm, bottom_margin = 4Plots.mm)

The first-order formulas from the exact ones ​

The three parameters are scaled by and the exact velocities expanded to first order in with SymPy.    with   tells SymPy that  , so that it takes   .

julia
V_S0, ΔV, ρₛ = symbols("V_S0 ΔV ρ", positive = true)
εₛ, δₛ, γₛ, τ, θ = symbols("ε δ γ τ θ", real = true)
ℂτ = ti_from_constants(V_S0 + ΔV, V_S0, τ * εₛ, τ * δₛ, τ * γₛ, [0, 0, 1]; form = :thomsen, density = ρₛ)
n = [sin(θ), 0, cos(θ)]
exact_s = wave_modes(ℂτ, ρₛ, n)
weak_s = weak_wave_modes(ℂτ, ρₛ, n)
first_order(V) = tsubs(V, τ => 0) + τ * tsubs(tdiff(V, τ), τ => 0)

For SH, SymPy reduces the difference between the series and Thomsen's formula to zero:

julia
tsimplify(first_order(exact_s.SH[1]) - weak_s.SH)

For qP and qSV the difference is evaluated at the parameters of each row of the table and at three angles; it vanishes to rounding:

julia
function series_gap(k)
    Δ = first_order(exact_s[k][1]) - weak_s[k]
    gaps = [
        N(
            tsubs(
                Δ, θ => ϑ, τ => 1, V_S0 => r["V_S0 (m/s)"] / 1000,
                ΔV => (r["V_P0 (m/s)"] - r["V_S0 (m/s)"]) / 1000, εₛ => r["epsilon"], δₛ => r["delta"], γₛ => r["gamma"],
                ρₛ => r["rho (g/cm3)"]
            )
        ) for r in rows, ϑ in (0.3, 0.8, 1.3)
    ]
    return maximum(abs ∘ float, gaps)
end
(qP = series_gap(:qP), qSV = series_gap(:qSV))

The same curvature, taken on the exact P velocity by two nested ForwardDiff derivatives, for every row;     (anellipticity) measures how far the P wave is from an elliptical one, for which and the horizontal velocity coincide:

julia
function moveout_from_curvature(V)
    V₀ = V(0.0)
    V″ = ForwardDiff.derivative(θ -> ForwardDiff.derivative(V, θ), 0.0)
    return sqrt(V₀^2 * (1 + V″ / V₀))
end
