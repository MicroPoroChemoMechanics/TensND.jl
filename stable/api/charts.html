Charts and coordinate conversions ​

A coordinate system as a map between coordinates and points, evaluated on numbers. Theory: Changes of coordinates; usage: Charts and coordinate conversions.

TensND.AbstractChart Type
julia
AbstractChart{dim}

A curvilinear coordinate system of dimension dim as a map: the Cartesian components of the point of coordinates ξ are coords_to_cartesian(chart, ξ), and the coordinates of the point x are cartesian_to_coords(chart, x).

Predefined: PolarChart, CylindricalChart, SphericalChart, ProlateSpheroidalChart, OblateSpheroidalChart, EllipsoidalChart, ToroidalChart.

TensND.PolarChart Type
julia
PolarChart()

Polar coordinates (r, θ): x₁ = r cos θ, x₂ = r sin θ.

TensND.CylindricalChart Type
julia
CylindricalChart()

Cylindrical coordinates (r, θ, z): x₁ = r cos θ, x₂ = r sin θ, x₃ = z.

TensND.SphericalChart Type
julia
SphericalChart()

Spherical coordinates in the order (θ, ϕ, r) of coorsys_spherical: x₁ = r sin θ cos ϕ, x₂ = r sin θ sin ϕ, x₃ = r cos θ.

TensND.ProlateSpheroidalChart Type
julia
ProlateSpheroidalChart(c)

Prolate spheroidal coordinates (ϕ, p, q) of axis 𝐞₃ and semi-focal distance c > 0, with -1 ≤ p ≤ 1 and q ≥ 1:

julia
x₁ = c √(1-p²) √(q²-1) cos ϕ,   x₂ = c √(1-p²) √(q²-1) sin ϕ,   x₃ = c p q.

The surfaces q = const are the confocal prolate spheroids of semi-axes c q along 𝐞₃ and c √(q²-1) across; the foci are the points ± c 𝐞₃.

See also OblateSpheroidalChart, coorsys_spheroidal.

TensND.OblateSpheroidalChart Type
julia
OblateSpheroidalChart(c)

Oblate spheroidal coordinates (ϕ, p, τ) of axis 𝐞₃ and semi-focal distance c > 0, with -1 ≤ p ≤ 1 and τ ≥ 0:

julia
x₁ = c √(1-p²) √(τ²+1) cos ϕ,   x₂ = c √(1-p²) √(τ²+1) sin ϕ,   x₃ = c p τ.

The surfaces τ = const are the confocal oblate spheroids of semi-axes c τ along 𝐞₃ and c √(τ²+1) across; the focal circle has radius c in the plane x₃ = 0. The chart is the prolate one continued to c → -i c, q → i τ.

See also ProlateSpheroidalChart, coorsys_spheroidal_oblate.

TensND.EllipsoidalChart Type
julia
EllipsoidalChart(h₂, h₃)

Ellipsoidal coordinates (ρ, μ, ν) of semi-focal distances h₂ > h₃ > 0, with h₁² = h₂² - h₃² and ν² ≤ h₃² ≤ μ² ≤ h₂² ≤ ρ²:

julia
x₁ = ρ μ ν / (h₂ h₃),
x₂ = √(ρ²-h₃²) √(μ²-h₃²) √(h₃²-ν²) / (h₁ h₃),
x₃ = √(ρ²-h₂²) √(h₂²-μ²) √(h₂²-ν²) / (h₁ h₂).

The surfaces ρ = const are the confocal ellipsoids of semi-axes ρ, √(ρ²-h₃²), √(ρ²-h₂²) along 𝐞₁, 𝐞₂, 𝐞₃; μ = const are hyperboloids of one sheet and ν = const hyperboloids of two sheets. For an ellipsoid of semi-axes a₁ > a₂ > a₃, h₂² = a₁² - a₃² and h₃² = a₁² - a₂², and its surface is ρ = a₁.

With the positive square roots, the chart covers the quarter space x₂ ≥ 0, x₃ ≥ 0, the sign of ν being that of x₁. The unit vectors (𝐞ᵨ, 𝐞ᵤ, 𝐞ᵥ), taken in the order of the coordinates, form a left-handed triad; (𝐞ᵨ, 𝐞ᵥ, 𝐞ᵤ) is right-handed.

See also coorsys_ellipsoidal.

TensND.ToroidalChart Type
julia
ToroidalChart(a)

Toroidal coordinates (ϕ, α, β) of axis 𝐞₃ and focal radius a > 0, with α ≥ 0 and -π < β ≤ π:

julia
x₁ = a sinh α cos ϕ / (cosh α - cos β),
x₂ = a sinh α sin ϕ / (cosh α - cos β),
x₃ = a sin β / (cosh α - cos β).

The surfaces α = const are the tori of center-line radius a coth α and tube radius a / sinh α, around the focal circle of radius a in the plane x₃ = 0, which is α → ∞. The surfaces β = const are the spherical caps through the focal circle, of centers a cot β 𝐞₃. The axis 𝐞₃ is α = 0, with the origin at β = π and the point at infinity at β = 0.

A torus of center-line radius R and tube radius r < R is the surface α = acosh(R / r) of the chart of focal radius a = √(R² - r²).

The unit vectors (𝐞ᵩ, 𝐞ₐ, 𝐞ᵦ), taken in the order of the coordinates, form a right-handed triad; 𝐞ₐ points toward the focal circle, into the torus α = const.

See also coorsys_toroidal.

TensND.coords_to_cartesian Function
julia
coords_to_cartesian(chart::AbstractChart, ξ) -> SVector

Cartesian components of the point whose coordinates in chart are ξ (a tuple or a vector). The result carries the element type of the coordinates and of the parameters of the chart together: duals and symbols pass through.

Examples

julia
julia> coords_to_cartesian(ProlateSpheroidalChart(1.0), (0.0, 0.0, 2.0)) ≈ [√3, 0, 0]
true

See also cartesian_to_coords, change_coords.

TensND.cartesian_to_coords Function
julia
cartesian_to_coords(chart::AbstractChart, x) -> SVector

Coordinates in chart of the point of Cartesian components x, the inverse of coords_to_cartesian. The inversion is in closed form and differentiable (ForwardDiff duals in x and in the parameters of the chart), away from the singular set of the chart (axis, foci, focal curves). On the focal circle of a ToroidalChart the coordinate α is infinite.

For an EllipsoidalChart, the coordinates returned are those of the mirror image of x in the quarter space x₂ ≥ 0, x₃ ≥ 0 that the chart covers: ν has the sign of x₁, and coords_to_cartesian(chart, cartesian_to_coords(chart, x)) ≈ (x₁, |x₂|, |x₃|).

Examples

julia
julia> chart = OblateSpheroidalChart(2.0); ξ = (0.3, -0.4, 1.5);

julia> cartesian_to_coords(chart, coords_to_cartesian(chart, ξ)) ≈ [ξ...]
true
TensND.change_coords Function
julia
change_coords(to::AbstractChart, from::AbstractChart, ξ) -> SVector

Coordinates in the chart to of the point whose coordinates in the chart from are ξ. Between two spheroidal charts of the same axis and different semi-focal distances, this is the change of coordinates that accompanies the re-expansion of spheroidal harmonics.

Examples

julia
julia> ξ₂ = change_coords(ProlateSpheroidalChart(2.0), ProlateSpheroidalChart(1.0), (0.3, 0.5, 3.0));

julia> coords_to_cartesian(ProlateSpheroidalChart(2.0), ξ₂) ≈ coords_to_cartesian(ProlateSpheroidalChart(1.0), (0.3, 0.5, 3.0))
true
TensND.unit_vectors Function
julia
unit_vectors(chart::AbstractChart, ξ) -> SMatrix

The unit vectors   of chart at the point of coordinates ξ, as the columns of a matrix of Cartesian components, in the order of the coordinates. The forms are closed and allocate nothing; duals and symbols pass through.

Examples

julia
julia> unit_vectors(CylindricalChart(), (1.0, π / 2, 0.0)) ≈ [0 -1 0; 1 0 0; 0 0 1]
true

See also lame_coefficients, coords_to_cartesian.

TensND.lame_coefficients Method
julia
lame_coefficients(chart::AbstractChart, ξ) -> SVector

The Lamé coefficients   of chart at the point of coordinates ξ, in the order of the coordinates, in closed form: duals and symbols pass through.

Examples

julia
julia> lame_coefficients(SphericalChart(), (π / 2, 0.0, 2.0)) ≈ [2, 2, 1]
true

See also unit_vectors.
