Tensors ​

The tensor hierarchy, component conversion and the Kelvin-Mandel map. Theory: Tensor algebra; usage: Tensors.

TensND.AbstractTens Type
julia
AbstractTens{order,dim,T}

Supertype of every tensor in TensND: a tensor of a given order and dim, with element type T.

A tensor is not an array. It is an array of components together with the basis those components refer to and the variance of each index, which is what lets tensors expressed in different frames be combined, and what makes comparing raw component arrays meaningless. See Bases and variance.

The concrete subtypes fall in two families:

FamilyTypesStores
generalTens, TensRotated, TensCanonical, TensOrthogonala full component array
structuredTensISO, TensTI, TensOrthoa few scalars plus an orientation

The type follows the basis: only the non-orthonormal cases carry a variance tuple. Accessors common to all of them are get_order, get_dim, get_basis, get_var, get_data and get_array.

TensND.Tens Type
julia
Tens{order,dim,T,A<:AbstractArray,B<:Basis}

Tensor type of any order defined by

  • a multidata of components (of any type inheriting from AbstractArray, e.g. Tensor or SymmetricTensor)

  • a basis of AbstractBasis type, whose concrete type is the parameter B

  • a tuple of variances (covariant :cov or contravariant :cont) of length equal to the order of the tensor

The variance tuple only matters when the basis is not orthonormal; on an orthonormal basis the covariant and contravariant components coincide, which is why TensCanonical, TensRotated and TensOrthonormal do not carry one. See Bases and variance.

Examples

Storing the covariant metric of a non-orthogonal basis as a twice-covariant tensor, and raising one index — which necessarily returns the identity, since gⁱᵏ gₖⱼ = δⁱⱼ:

julia
julia> ℬ = Basis(Sym[1 0 0; 0 1 0; 0 1 1]) ;

julia> T = Tens(metric(ℬ, :cov), ℬ, (:cov, :cov))
3×3 Tens{2, 3, Sym, SymmetricTensor{2, 3, Sym, 6}}:
 1  0  0
 0  2  1
 0  1  1

julia> components(T, (:cont, :cov))
3×3 Matrix{Sym}:
 1  0  0
 0  1  0
 0  0  1

See also components, change_tens, get_var.

TensND.sqnorm Function
julia
sqnorm(t::AbstractTens)

The square of norm(t), the self-contraction uᵢuⁱ, tᵢⱼtⁱʲ or tᵢⱼₖₗtⁱʲᵏˡ, computed without the square root: smooth at zero, where the derivative of norm is not, and exact for symbolic components. On complex components it is Hermitian, t̄ ⋅ t: the contractions do not conjugate (they are contractions), so the self-contraction of a complex tensor is not its squared norm. Real element types, duals and symbols included, keep the plain self-contraction, with no abs in a symbolic result.

TensND.pprint Function
julia
pprint(t::AbstractTens; vec = '𝐞', coords = 1:dim)
pprint(t::AbstractTens, CS::AbstractCoorSystem; vec = '𝐞')

Print t expanded on its basis — as a sum of basis products such as (σʳʳ)𝐞ʳ⊗𝐞ʳ + (σᶿᶿ)𝐞ᶿ⊗𝐞ᶿ — instead of as an array of components.

This is a display helper: it writes to stdout and returns nothing. For symbolic results it is far more readable than the component array, and it is the natural way to report a field computed in a curvilinear frame. Zero components are omitted, and a vanishing tensor prints as 0.

Passing a coordinate system names the basis vectors after its coordinates; @set_coorsys makes that the default, so pprint(t) alone then prints 𝐞ʳ, 𝐞ᶿ, … rather than 𝐞₁, 𝐞₂, ….

Formerly intrinsic, then print_tensor

intrinsic was misleading: what is printed is explicitly basis dependent — it changes with the chart — whereas "intrinsic" denotes the basis-free form. print_tensor was misleading in turn, because the fallback below accepts a scalar, and pprint is the name MPCM already uses for a generic pretty-printer (ChemistryLab.pprint). Both former names still work and forward here, with a deprecation warning.

Examples

julia
julia> Spherical = coorsys_spherical() ; 𝐞ᶿ, 𝐞ᵠ, 𝐞ʳ = unitvec(Spherical) ;

julia> @set_coorsys Spherical

julia> pprint(𝐞ʳ ⊗ 𝐞ʳ + 2 * 𝐞ᶿ ⊗ 𝐞ᶿ)   # spherical coordinates are ordered (θ, ϕ, r)
(2)𝐞ᶿ⊗𝐞ᶿ + 𝐞ʳ⊗𝐞ʳ

Applied to anything that is not a tensor — a scalar field, typically, so that laplacian(f(r)) |> pprint works in a pipeline — it falls back to the rich text/plain display, which for a symbolic expression is SymPy's two-dimensional form:

julia
julia> laplacian(SymFunction("f", real = true)(r)) |> pprint
              d
 2          2⋅──(f(r))
d             dr
───(f(r)) + ──────────
  2             r
dr

Tensor coefficients are deliberately not printed that way: a multi-line coefficient interpolated into (…)𝐞ʳ⊗𝐞ʳ + (…)𝐞ᶿ⊗𝐞ᶿ would destroy the layout that makes the expanded form readable in the first place.

See also get_array, components.

TensND.mandel_rotation Function
julia
mandel_rotation(θ, ϕ, ψ) → SMatrix{6,6}
mandel_rotation(R::AbstractMatrix) → SMatrix{6,6}

6×6 Kelvin-Mandel (Bond) rotation matrix, from ZYZ Euler angles (θ, ϕ, ψ) or directly from a 3×3 rotation matrix R whose columns are the new basis vectors.

Transforms a 6×6 KM matrix as C' = Q' · C · Q with Q = mandel_rotation(…); Q is orthogonal.

Built entirely with SMatrix / ntuple, so it is compatible with ForwardDiff.Dual and with non-isbits element types such as SymPyPythonCall.Sym or Symbolics.Num, for which an MMatrix{6,6,T}(undef) cannot even be constructed.

Examples

julia> size(Q)
(6, 6)
TensND.diff_with_basis Function
julia
diff_with_basis(t::AbstractTens, args...; kwargs...)

Differentiate t including its basis, then re-express the result on the original basis and variance.

This differs from ∂ applied componentwise: when the basis itself depends on the differentiation variable — as a rotated or curvilinear frame does — the derivative of the basis vectors contributes, and dropping it is the classic way to lose the Christoffel terms.

Tensors.jl and the Voigt forms ​

Components in the canonical basis, whatever basis a tensor is written in: the form a finite-element code (Ferrite among others) and an Abaqus-style interface expect.

TensND.to_tensors Function
julia
to_tensors(t::AbstractTens{2,dim}) -> Tensors.SymmetricTensor{2,dim}
to_tensors(t::AbstractTens{4,dim}) -> Tensors.SymmetricTensor{4,dim}

The Tensors.jl counterpart of t, in the canonical basis: the components a finite-element code (Ferrite among others) contracts with its shape-function gradients.

A second-order tensor is symmetrized. A fourth-order one is assumed to have the minor symmetries, as stiffnesses, compliances and concentration tensors do; the major symmetry is not assumed, SymmetricTensor{4,3} holding 36 independent components.

Not get_array

get_array(t) and t[i, j, k, l] are the components of t in its own basis. For a tensor written in a rotated basis they are not the canonical ones; to_tensors performs the change of basis.

TensND.voigt_stress Function
julia
voigt_stress(σ::AbstractTens{2,3}) -> NTuple{6}
voigt_strain(ε::AbstractTens{2,3}) -> NTuple{6}

Canonical components of a symmetric second-order tensor in the Voigt order (11, 22, 33, 12, 13, 23) of Abaqus-style interfaces.

The two differ by the engineering shears: voigt_strain doubles the off-diagonal terms ( ), voigt_stress does not. Two functions rather than one with a flag, because a single voigt is the classic way to lose a factor of two between the strain that goes in and the stress that comes out. Voigt is not an isometry, unlike the Kelvin–Mandel form of mandel, and belongs only at the boundary with codes that demand it.

Symmetric parts ​

Methods of the Tensors.jl functions, which keep the symmetry class of a structured tensor where the class allows it.

Tensors.majorsymmetric Method
julia
Tensors.majorsymmetric(t::AbstractTens{4}) -> AbstractTens{4}

Major-symmetric part   of a fourth-order tensor, a method of the Tensors.jl function.

The symmetry class is kept: an isotropic, cubic or nine-constant orthotropic tensor is its own major-symmetric part, a twelve-constant orthotropic one (a product of orthotropic tensors lands there) returns the nine-constant form on the same frame, and a transversely isotropic tensor in the six- or eight-parameter Walpole form (a product of TI tensors lands there) returns the five-parameter form about the same axis. A general tensor stays in its basis; in a basis that is not orthonormal, the transpose pairs components of the same variance, so they are first written with the variance of the first pair on the second as well.

See also Tensors.symmetric for a second-order tensor.

Tensors.symmetric Method
julia
Tensors.symmetric(t::AbstractTens{2}) -> AbstractTens{2}

Symmetric part   of a second-order tensor, a method of the Tensors.jl function. An isotropic or transversely isotropic tensor keeps its class (the skew part c·w of a three-parameter TensTI{2} goes); a general one stays in its basis, its components written with one variance before transposing.

Coefficients and flat vectors ​

The tensor of the class of t — same order, same axis or frame — whose coefficients (get_data, in the same order) are data, a tuple or a vector. TensND.param_norms Function
julia
param_norms(t) → NTuple

The Frobenius norms of the tensors the coefficients of t multiply, ‖rebuild(t, eᵢ)‖: (1, √5) for the isotropic (𝕁, 𝕂) in 3-D, the norms of the Walpole, orthotropic or cubic basis tensors for the other classes. These bases are orthogonal, so norm(t) == norm(param_norms(t) .* get_data(t)): the weights that make the Euclidean norm of the coefficients the norm of the tensor. For a generic tensor, whose to_vector coordinates are orthonormal Kelvin-Mandel components, they are all one.

Kelvin-Mandel blocks about a normal ​

In a frame whose third axis is a normal n, the in-plane and out-of-plane symmetric tensors split the Kelvin-Mandel slots; the maps below work on that partition, with no pivoting and no SVD (duals and symbols go through).

TensND.MANDEL_IP Constant
julia
MANDEL_IP
MANDEL_OP

The Kelvin-Mandel slots of the in-plane symmetric tensors, (1, 2, 6) for (ℓ⊗ℓ, m⊗m, √2 ℓ⊗ˢm), and of the out-of-plane ones, (3, 4, 5) for (n⊗n, √2 m⊗ˢn, √2 ℓ⊗ˢn), in an orthonormal frame (ℓ, m, n) whose third axis is the normal n. Across the interfaces of a laminate normal to n, the in-plane strain and the out-of-plane stress are continuous.

TensND.MANDEL_OP Constant

The Kelvin-Mandel slots of the out-of-plane symmetric tensors; see MANDEL_IP.

TensND.mandel_inv_schur Function
julia
mandel_inv_schur(M) → SMatrix{6,6}

The inverse of a 6×6 Kelvin-Mandel matrix by block elimination on the in-plane / out-of-plane partition: two 3×3 inverses by cofactors and a Schur complement, with no pivoting and no factorization, so that it holds for duals and for symbols, where an LU factorization pivots on values. Needs the out-of-plane block and the in-plane Schur complement invertible, as they are for any stiffness whose acoustic tensor about n is positive definite.

TensND.plane_pinv Function
julia
plane_pinv(M) → SMatrix{6,6}
plane_pinv2(K) → SMatrix{3,3}

The Moore-Penrose pseudo-inverse of the out-of-plane part of a 6×6 Kelvin-Mandel matrix (plane_pinv): the inverse of its mandel_op_block, embedded back. For the Kelvin-Mandel matrix of a stiffness ℂ it is the Hill tensor of a flat inclusion of normal n, n ⊗ˢ (n⋅ℂ⋅n)⁻¹ ⊗ˢ n; for a matrix supported on the out-of-plane subspace it is its pseudo-inverse. plane_pinv2 is the order-2 counterpart for a 3×3 matrix written in the frame (ℓ, m, n): (1/K₃₃) n⊗n. No SVD, so duals and symbols go through.

TensND.plane_pinv2 Function

The order-2 out-of-plane pseudo-inverse (1/K₃₃) n⊗n; see plane_pinv.

TensND.deviatoric_pinv Function
julia
deviatoric_pinv(M) → SMatrix{6,6}

The Moore-Penrose pseudo-inverse of a 6×6 Kelvin-Mandel matrix supported on the deviators (𝕁 M = M 𝕁 = 0): its inverse on the deviatoric subspace, zero on volume changes. For the deviatoric stiffness of an incompressible medium it is the compliance on deviators, and conversely. Written (M + 𝕁)⁻¹ − 𝕁, the volume changes taking the identity while the matrix is inverted: M + 𝕁 is invertible whenever M is on deviators, and is inverted by mandel_inv_schur, so that duals and symbols go through (no SVD, no pivoting). That M acts on deviators only is assumed, not checked: the check would be a value test.

TensND.acoustic_tensor Function
julia
acoustic_tensor(M::AbstractMatrix) → SMatrix{3,3}
acoustic_tensor(ℂ::AbstractTens{4,3}, n) → Tens{2,3}

The acoustic tensor K = n⋅ℂ⋅n, Kᵢⱼ = nₖ ℂₖᵢₗⱼ nₗ: read off the out-of-plane block of a 6×6 Kelvin-Mandel matrix written in a frame whose third axis is n (its Mandel weights and the (3, 2, 1) order of its slots undone), or computed from a tensor and a direction.

TensND.compliance_op_block Function
julia
compliance_op_block(X) → SMatrix{3,3}

The slot-ordered out-of-plane block (mandel_op_block) of the fourth-order compliance X ⊗ˢ n ⊗ˢ n — the strain (X⋅(σ⋅n)) ⊗ˢ n — from the symmetric 3×3 matrix X written in the frame (ℓ, m, n): the map acoustic_tensor inverts on the compliance side, Ŝₐᵦ = X_{π(a)π(b)} / (sₐ sᵦ), π = (3, 2, 1), s = (1, √2, √2). For a spring interface of compliance X, mandel_op_embed(compliance_op_block(X)) is its Kelvin-Mandel matrix.
