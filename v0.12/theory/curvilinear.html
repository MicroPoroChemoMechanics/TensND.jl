Curvilinear differential calculus ​

Manual: Coordinate systems (symbolic) · Coordinate systems (numerical) · Charts and coordinate conversions

A coordinate system is built in four steps: a position vector as a function of the coordinates, its derivatives (the natural basis), their norms and directions (the Lamé coefficients and the normalized basis), and the rate at which the basis turns (the Christoffel symbols). The differential operators follow. This page defines each step and says how TensND carries it out, symbolically (src/coorsystems.jl) or by automatic differentiation (src/coorsystems_num.jl); the systems it predefines are on the next three pages, Classical coordinate systems, Spheroidal coordinates and Ellipsoidal coordinates. A classical treatment of the underlying tensor analysis is Simmonds (1994).

Building a coordinate system ​

TensND builds a system from what is known about it, by one of four routes.

GivenConstructorComputed
nothing: a predefined systemcoorsys_spherical(), coorsys_spheroidal(), coorsys_ellipsoidal(), …—

The first three return an exact system, whose operators return expressions; the last one a pointwise system, whose operators return functions of the point. The predefined systems use the second route, since their bases and Lamé coefficients are known in a simpler form than a computer algebra system would find. Coordinate systems (symbolic) and Coordinate systems (numerical) show each route.

A PointwiseGeometry stores the geometry as three closures — χ_func (Lamé), R_func (the rotation to the normalized frame) and Γ_func (Christoffel, with the   convention) — so a custom system needs only a differentiable position map, with no symbolic setup at all.

Because everything downstream is generic in the element type, ForwardDiff.Dual numbers flow through the operators in both directions: an operator result can be differentiated again with respect to the evaluation point, and with respect to a parameter carried by the field itself. The internal buffers promote the element type of the geometry (the Lamé coefficients) with that of the field value, so a Dual-valued field evaluated on a Float64 coordinate system is handled correctly.
