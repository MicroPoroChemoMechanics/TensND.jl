Spheroidal harmonics ​

Legendre functions, the harmonics of the spheroidal charts and their re-expansion from one chart to another. Theory: Spheroidal harmonics and their re-expansion; usage: Spheroidal harmonics.

TensND.legendre_P Function
julia
legendre_P(N, m, x) -> Vector

Associated Legendre functions of the first kind on the cut, |x| ≤ 1: v[n+1] = P_n^m(x) = (-√(1-x²))^m dᵐP_n/dxᵐ for m ≤ n ≤ N, and zero for n < m. The upward recurrence in the degree is stable there. The argument may be a number, a dual or a symbol.

Examples

julia
julia> legendre_P(2, 1, 0.5) ≈ [0, -√0.75, -1.5 * √0.75]
true

See also radial_P, radial_Q.

TensND.radial_P Function
julia
radial_P(chart, N, m, ζ) -> Vector

Radial factor of the interior harmonics of chart, v[n+1] for m ≤ n ≤ N (zero for n < m):

  • ProlateSpheroidalChart: P_n^m(q) = (√(q²-1))^m dᵐP_n/dqᵐ, q ≥ 1;

  • OblateSpheroidalChart: 𝒫_n^m(τ) = i⁻ⁿ P_n^m(iτ), τ ≥ 0, real;

  • SphericalChart: rⁿ.

These are the dominant solutions of their recurrences, which are run upward. The argument may be a number, a dual or a symbol.

See also radial_Q, interior_harmonics.

TensND.radial_Q Function
julia
radial_Q(chart, N, m, ζ) -> Vector

Radial factor of the exterior harmonics of chart, v[n+1] for m ≤ n ≤ N (zero for n < m):

  • ProlateSpheroidalChart: Q_n^m(q) = (√(q²-1))^m dᵐQ_n/dqᵐ, q > 1;

  • OblateSpheroidalChart: 𝒬_n^m(τ) = iⁿ⁺¹ Q_n^m(iτ), τ > 0, real;

  • SphericalChart: r⁻ⁿ⁻¹.

𝖰_n^m is the minimal solution of its recurrence: run upward, the recurrence loses it to rounding. The ratios 𝖰_n^m/𝖰_{n-1}^m are therefore computed downward, from their limit e^{-ξ} far above N, and the first value follows from the Casoratian with the dominant solution at the lowest degree,

julia
𝖯_{m+1}^m 𝖰_m^m - s 𝖯_m^m 𝖰_{m+1}^m = (-1)^m (2m)!,

with s = 1 (prolate) or s = -1 (oblate). The result is accurate to rounding at every degree and differentiable (duals in ζ). It is singular on the focal set (q = 1, τ = 0).

See also radial_P, exterior_harmonics.

TensND.interior_harmonics Function
julia
interior_harmonics(chart, N, m, ξ) -> Vector

Meridian part of the interior harmonics of order m ≥ 0 of chart at the point of coordinates ξ: v[n+1] = P_n^m(p) 𝖯_n^m(ζ) for m ≤ n ≤ N, or rⁿ P_n^m(cos θ) in the SphericalChart. Multiplied by cos mϕ or sin mϕ, each is harmonic and regular on the focal set of the chart.

See also exterior_harmonics, interior_reexpansion.

TensND.exterior_harmonics Function
julia
exterior_harmonics(chart, N, m, ξ) -> Vector

Meridian part of the exterior harmonics of order m ≥ 0 of chart at the point of coordinates ξ: v[n+1] = P_n^m(p) 𝖰_n^m(ζ) for m ≤ n ≤ N, or r⁻ⁿ⁻¹ P_n^m(cos θ) in the SphericalChart. Multiplied by cos mϕ or sin mϕ, each is harmonic off the focal set of the chart and vanishes at infinity.

See also interior_harmonics, exterior_reexpansion.

TensND.reexpansion_polynomials Function
julia
reexpansion_polynomials(n, imax, x) -> Vector

The polynomials of the re-expansion of spheroidal harmonics, Φ[i+1] = Φᵢ⁽ⁿ⁾(x) for 0 ≤ i ≤ imax:

julia
Φᵢ⁽ⁿ⁾(x) = (2n+4i+1)/(2n+1) · (n+½)ᵢ/i! · ₂F₁(-i, n+i+½; n+3/2; x)
         = (2n+4i+1)/(2n+2i+1) · Pᵢ^(n+½, -1)(1-2x),

with Pᵢ^(α, β) the Jacobi polynomial: Φ₀ = 1, Φ₁ = (2n+5)(1-x)/2, and Φᵢ(1) = 0 for i ≥ 1. They are evaluated by the three-term recurrence of the Jacobi polynomials; the hypergeometric sum cancels for 0 < x < 1.

TensND.interior_reexpansion Function
julia
interior_reexpansion(to, from, n, m) -> Vector

Coefficients L[k+1], 0 ≤ k ≤ ⌊(n-m)/2⌋, of the interior harmonic of degree n and order m of the chart from in the interior harmonics of the coaxial chart to, of degrees j = n - 2k:

julia
P_n^m(p₁) 𝖯_n^m(ζ₁) = Σₖ Lₖ P_j^m(p₂) 𝖯_j^m(ζ₂).

The sum is finite and the identity holds at every point: both sides are the same polynomial of the Cartesian coordinates. Between two spheroidal charts,

julia
Lₖ = (-s₁)ᵏ (c₂/c₁)ʲ · (n+m)! (j-m)! / ((n-m)! (j+m)!) · (2j+1)/(2n+1) · Φₖ⁽ʲ⁾(s₂c₂²/(s₁c₁²)),

with Φₖ⁽ʲ⁾ of reexpansion_polynomials. A SphericalChart on either side gives the expansion in, or of, the solid harmonic rⁿ P_n^m(cos θ).

Examples

julia
julia> from, to = OblateSpheroidalChart(1.0), ProlateSpheroidalChart(0.6); x = [0.7, -0.4, 0.3];

julia> L = interior_reexpansion(to, from, 4, 2);

julia> lhs = interior_harmonics(from, 4, 2, cartesian_to_coords(from, x))[5];

julia> rhs = sum(L .* interior_harmonics(to, 4, 2, cartesian_to_coords(to, x))[5:-2:3]);

julia> lhs ≈ rhs
true

See also exterior_reexpansion.

TensND.exterior_reexpansion Function
julia
exterior_reexpansion(to, from, n, m, imax) -> Vector

Coefficients K[i+1], 0 ≤ i ≤ imax, of the exterior harmonic of degree n and order m of the chart from in the exterior harmonics of the coaxial chart to:

julia
P_n^m(p₁) 𝖰_n^m(ζ₁) = Σᵢ Kᵢ P_{n+2i}^m(p₂) 𝖰_{n+2i}^m(ζ₂).

Between two spheroidal charts of semi-focal distances c₁, c₂ and signs s₁, s₂ (1 prolate, -1 oblate),

julia
Kᵢ = (-s₂)ⁱ (c₁/c₂)ⁿ⁺¹ · (n+m)! (n+2i-m)! / ((n-m)! (n+2i+m)!) · Φᵢ⁽ⁿ⁾(s₁c₁²/(s₂c₂²)),

with Φᵢ⁽ⁿ⁾ of reexpansion_polynomials. A SphericalChart on either side gives the expansion in, or of, the solid harmonic r⁻ⁿ⁻¹ P_n^m(cos θ). The series converges outside the smallest coordinate surface of to that encloses the focal set of from, see reexpansion_bound.

Examples

julia
julia> from, to = ProlateSpheroidalChart(1.0), ProlateSpheroidalChart(1.5); x = [0.7, -0.4, 2.1];

julia> K = exterior_reexpansion(to, from, 2, 1, 40);

julia> lhs = exterior_harmonics(from, 2, 1, cartesian_to_coords(from, x))[3];

julia> rhs = sum(K .* exterior_harmonics(to, 82, 1, cartesian_to_coords(to, x))[3:2:end]);

julia> isapprox(lhs, rhs; rtol = 1e-12)
true

See also interior_reexpansion.

TensND.reexpansion_bound Function
julia
reexpansion_bound(to, from)

The value of the radial coordinate of to beyond which the exterior re-expansion of exterior_reexpansion converges: the coordinate surface of to through the edge of the focal set of from. Below it the series diverges. The terms of the series decay as e^{-2i(ξ-ξ*)}, with ξ = arccosh q or arcsinh τ and ξ* its value at the bound.

from → tobound
prolate c₁ → prolate c₂q₂ > max(1, c₁/c₂)
oblate c₁ → oblate c₂τ₂ > √(max(0, c₁²/c₂² - 1))
prolate c₁ → oblate c₂τ₂ > c₁/c₂
oblate c₁ → prolate c₂q₂ > √(1 + c₁²/c₂²)
spheroidal c₁ → sphericalr > c₁
spherical → spheroidalthe focal set of to
