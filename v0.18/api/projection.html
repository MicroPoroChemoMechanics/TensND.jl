Projection ​

Closest tensor of a prescribed material symmetry, and symmetry detection. Theory: Projection onto a symmetry class; usage: Projection.

TensND.project Function
julia
project(A::AbstractArray{T,4}, ::Val{:TI}, n) → (TensTI{4, T, 5}, d, drel)

Project a 4th-order tensor A (3×3×3×3) onto the transversely isotropic subspace with fixed symmetry axis n. Returns a major-symmetric TensTI{4, T, 5}.

The projection minimizes the Frobenius distance ‖B − A‖ over all TI tensors B with axis n.

Returns a 3-tuple (B, d, drel):

  • B: the projected TensTI{4, T, 5}

  • d: absolute Frobenius distance ‖B − A‖

  • drel: relative distance d / ‖A‖

Examples

julia
julia> n = [0., 0., 1.];

julia> C = ti_from_constants(10., 3., 2.5, 12., 2., n);

julia> B, d, drel = project(get_array(C), :TI, n);

julia> d < 1e-12
true

julia> ti_constants(B) == ti_constants(C)
false
julia
project(A::AbstractArray{T,2}, ::Val{:TI}, n) → (TensTI{2,T,2}, d, drel)

Project a 2nd-order tensor A (3×3) onto the transversely isotropic subspace with fixed symmetry axis n. Returns a TensTI{2,T,2}.

In the rotated frame where e₃ = n:

  • a = (M[1,1] + M[2,2]) / 2 (transverse)

  • b = M[3,3] (axial)

Examples

julia
julia> n = [0., 0., 1.];

julia> A = [5. 0 0; 0 5 0; 0 0 8];

julia> B, d, drel = project(A, :TI, n);

julia> B.data
(5.0, 8.0)

Project a 4th-order tensor A (3×3×3×3) onto the orthotropic subspace with fixed material frame frame. Returns a TensOrtho{4, 3,T,9}.

Examples

julia
julia> frame = CanonicalBasis{3,Float64}();

julia> t = TensOrtho(10., 8., 12., 3., 2.5, 1.5, 2., 3., 3.5, frame);

julia> B, d, drel = project(get_array(t), :ORTHO, frame);

julia> d < 1e-12
true
julia
project(A::AbstractArray{T,4}, ::Val{:CUBIC}, frame::OrthonormalBasis{3}) → (TensCubic{3, T}, d, drel)

Project a 4th-order tensor onto the cubic subspace with cube axes frame.

Read drel rather than trusting the projection. Where the morphology and the medium leave the octahedral group invariant, the answer belongs to the class by group theory, so its distance to it is discretization error and nothing else — an error estimate that costs nothing and involves no reference solution. Where they do not, drel says how much was discarded, and the projection is a fit like any other.

Examples

julia
julia> frame = CanonicalBasis{3,Float64}();

julia> t = cubic_from_constants(10.0, 4.0, 2.0, frame);

julia> B, d, drel = project(get_array(t), :CUBIC, frame);

julia> d < 1e-12
true

See also best_fit_cubic, cubic_anisotropy.

julia
project(A::AbstractArray{T,2}, ::Val{:CUBIC}, frame) → (TensISO{2,3,T}, d, drel)

At order two the cubic class is the isotropic class, the octahedral group leaving no second-order tensor invariant but a multiple of the identity. The frame is accepted and ignored, and the isotropic projection is returned.

That is not a shortcut: it is why a cube-symmetric pore has a single scalar resistivity contribution while its compliance contribution needs three constants, and why a conduction computation on such a shape carries no anisotropy signal whatever the shape does in elasticity.

julia
project(A::AbstractArray{T,2}, ::Val{:ORTHO}, frame::OrthonormalBasis{3}) → (TensOrtho{2, 3,T,3}, d, drel)

Project a 2nd-order tensor A (3×3) onto the orthotropic subspace with fixed material frame frame. The projection is diag(M₁₁, M₂₂, M₃₃) in the material frame, returned as a TensOrtho{2, 3} on that frame (as the TI projection returns a TensTI{2}).

Examples

julia
julia> frame = CanonicalBasis{3,Float64}();

julia> A = [5. 1 2; 1 8 3; 2 3 12];

julia> B, d, drel = project(A, :ORTHO, frame);

julia> get_array(B) ≈ diagm([5., 8., 12.])
true
julia
project(A::AbstractArray, sym::Symbol, arg) → (projected, d, drel)

Convenience dispatch: project(A, :TI, n) calls project(A, Val(:TI), n).

julia
project(A::AbstractArray{T,4}, ::Val{:TI}) where {T<:AbstractFloat}

Find the best TI approximation of A over all symmetry axes. The axis is searched — the objective screened on 200 axes, Newton's method on the angles from the best ones, from the eigenstructure candidate and from e₃ — with no random step, so a call is repeatable to the bit.

See also project(A, ::Val{:TI}, n) for fixed-axis projection.

julia
project(A::AbstractArray{T,2}, ::Val{:TI}) where {T<:AbstractFloat}

Find the best TI approximation of a 2nd-order tensor A over all symmetry axes. No search is needed: the axis is an eigenvector of the smallest or the largest eigenvalue of the symmetric part of A, whichever gives the closer tensor.

julia
project(A::AbstractArray{T,4}, ::Val{:ORTHO}) where {T<:AbstractFloat}

Find the best orthotropic approximation of A over all material frames. The frame is searched as the TI axis is (400 frames screened, Newton's method on the best ones, on the eigenstructure candidate and on the canonical frame).

julia
project(A::AbstractArray{T,4}, ::Val{:CUBIC}) where {T<:AbstractFloat}

Find the best cubic approximation of A over all cube orientations, searched as an orthotropic frame is, but with no eigenstructure candidate, there being none for a cubic tensor.

The octahedral group is discrete, but the orientation of the cube is not: it is an ordinary rotation, so the objective is smooth in the Euler angles exactly as it is for a TI axis or an orthotropic frame. The only trace the group leaves is that the optimum is 24-fold degenerate — the optimizer returns one of the 24 equivalent frames, and they all describe the same tensor with the same coefficients (see TensCubic).

See also project(A, ::Val{:CUBIC}, frame) for fixed-frame projection.

julia
project(A::AbstractArray{T,2}, ::Val{:CUBIC})

At order two the cubic class is the isotropic class, which has no orientation to optimize, so this is the isotropic projection, for any element type the isotropic one takes.

julia
project(A::AbstractArray{T,2}, ::Val{:ORTHO}) where {T<:AbstractFloat}

Find the best orthotropic approximation of a 2nd-order tensor A over all material frames. No search is needed: it is the eigenframe of the symmetric part of A, in which the projection keeps all of that part.

julia
project(t, ::Val{:TI6}, n) → (TensTI{4,T,6}, d, drel)

Projection of a fourth-order tensor with the minor symmetries onto the transversely isotropic tensors about n without major symmetry: the six Walpole coefficients, ℓ₃ ≠ ℓ₄ allowed — the class of a strain or flux concentration tensor, where project(A, Val(:TI), …) returns the major-symmetric five. It is the exact average about n (transverse_isotropify) without its two coefficients odd in n (ℓ₇, ℓ₈), which a reflection through the plane normal to n reverses: the orthogonal projection onto the tensors invariant under that reflection too. d is the Frobenius distance to t, drel its ratio to ‖t‖.

julia
project(A::AbstractArray{T,4}, ::Val{:ORTHO}, frame::OrthonormalBasis{2}) → (TensOrtho{4,2}, d, drel)
project(A::AbstractArray{T,4}, ::Val{:CUBIC}, frame::OrthonormalBasis{2}) → (TensCubic{2}, d, drel)
project(A::AbstractArray{T,2}, ::Val{:ORTHO}, frame::OrthonormalBasis{2}) → (TensOrtho{2,2}, d, drel)

The closest orthotropic or square tensor of the plane in the frame frame (Basis(θ), CanonicalBasis{2, T}()), with its distance d to A and the relative one drel: in the frame, the entries C₁₁₁₂, C₂₂₁₂ of the Kelvin-Mandel matrix are dropped, and C₁₁₁₁, C₂₂₂₂ averaged for the square class. The orthotropic projection is major-symmetric (four constants). At order 2 the orthotropic projection is the diagonal in the frame, and the square one the isotropic one.

Without a frame, project(t, :ORTHO) and project(t, :CUBIC) find the best one in closed form: see Projections in the plane.

TensND.best_sym_tens Function
julia
best_sym_tens(t; proj=(:ISO, :CUBIC, :TI, :ORTHO), ε=1e-6, optimize_angles=false)

Find the best (most restrictive) symmetry of tensor t by trying each symmetry class in proj (from most to least symmetric) and accepting the first whose relative projection error is below ε.

  • optimize_angles=false (default, cheap path, no optimization): the :ISO projection is closed-form; for :TI the symmetry axis is taken from t itself (if it is a structured TI container) or derived from the Kelvin-Mandel eigenstructure (otherwise); for :ORTHO the material frame is taken from t or derived likewise.

  • optimize_angles=true: the :TI axis and the :ORTHO and :CUBIC frames are searched by project (a screening of fixed orientations, then Newton's method on the best ones).

Returns (projected, d, drel, sym) where sym ∈ {:ISO, :CUBIC, :TI, :ORTHO, :ANISO}.

Examples

julia
julia> n = [0., 0., 1.];

julia> C = ti_from_constants(10., 3., 2.5, 12., 2., n);

julia> _, _, _, sym = best_sym_tens(C);

julia> sym === :TI
true

See also best_sym_tens(t, n_or_frame) for fixed-axis/frame use, project.

julia
best_sym_tens(t, n_or_frame; proj=(:ISO, :CUBIC, :TI, :ORTHO), ε=1e-6)

Find the best symmetry of tensor t with a fixed symmetry axis n (for TI) or material frame frame (for ORTHO). No rotation optimization is performed.

  • n_or_frame: a vector (axis for TI) or OrthonormalBasis{3} (frame for ORTHO and CUBIC). For ISO projection the extra argument is ignored.

Because there is one argument for two kinds of orientation, the classes it cannot serve are dropped from proj: an axis leaves :ISO and :TI, a frame leaves :ISO, :CUBIC and :ORTHO. Pass the kind that matches the classes you mean to test.

Returns (projected, d, drel, sym).

Examples

julia
julia> n = [0., 0., 1.];

julia> C = ti_from_constants(10., 3., 2.5, 12., 2., n);

julia> _, _, drel, sym = best_sym_tens(C, n);

julia> sym == :TI && drel < 1e-12
true

TensND.iscubic Function
julia
iscubic(t) -> Bool

Whether t is stored as a TensCubic. A type-level query, like isisotropic and istransverselyisotropic: it says what the container guarantees, not whether the components happen to satisfy a tighter symmetry.

julia
iscubic(A::AbstractArray, frame::OrthonormalBasis{3}; ε = 1.0e-6) -> Bool

Whether A is cubic about frame to within ε, measured as the relative Frobenius distance to the class.

The value-level companion of the type-level iscubic(::TensCubic), exactly as for isisotropic, istransverselyisotropic and isorthotropic: the first asks what the components say, the second what the container guarantees.

julia
iscubic(A::AbstractArray; ε = 1.0e-6) -> Bool

Whether A is cubic about some cube, the cube orientation being searched (project(A, :CUBIC)). Unlike istransverselyisotropic and isorthotropic it has no cheap alternative: every second-order contraction of a cubic tensor is isotropic, so no eigenframe reveals where the cube points and there is nothing to start from but a search.

Give the frame — iscubic(A, frame) — whenever it is known; that path is exact and costs one projection.

TensND.best_fit_iso Function
julia
best_fit_iso(t::AbstractTens) -> TensISO

Orthogonal (Frobenius) projection of t onto span(𝕁, 𝕂) at order 4, onto span(𝟏) at order 2 — the projection component of project(Val(:ISO), t).

For a minor-symmetric tensor this coincides with the exact SO(3) average isotropify; for a general one it does not, and the average is the meaningful object.

TensND.best_fit_ti Function
julia
best_fit_ti(t::AbstractTens{4,3}, axis) -> TensTI{4,T,5}
best_fit_ti(t::AbstractTens{2,3}, axis) -> TensTI{2,T,2}

Orthogonal (Frobenius) projection of t onto the major-symmetric Walpole span about axis — the projection component of project(Val(:TI), t, axis).

A projection, not an orientation average

It forces major symmetry, (ℓ₃+ℓ₄)/2, and drops the antisymmetric azimuthal couplings ℓ₇, ℓ₈. On a concentration tensor that content is physical and its loss is silent. Use transverse_isotropify to average, and this only to report parameters.

Unlike best_fit_ti, this loses nothing that a major-symmetric result would have kept: the cubic class is automatically major-symmetric, so there is no antisymmetric content to drop silently. What it does discard is everything outside the class, and project reports how much.

At order two it returns an isotropic tensor, the two classes coinciding there.

TensND.project_exact Function
julia
project_exact(t::AbstractTens, class, args...; rtol = 1.0e-10)

The tensor t written in the symmetry class class (:ISO, :TI, :ORTHO, :CUBIC, or their Val), with the axis or the frame the class needs, when it belongs to it: the projection of project if its relative distance to t is at most rtol, nothing otherwise. Where best_fit_iso and its companions return the closest tensor of the class whatever the distance, this one changes only how a tensor is stored.

A distance between symbolic tensors cannot be compared with a tolerance: of a symbolic tensor only an isotropic one, which every class contains, is written in the class; any other gives nothing.

Distances and closest tensors ​

Distances between symmetric tensors that treat a stiffness and its compliance alike, and the tensor of a symmetry class closest to a tensor in the sense of each. Theory: Distances between elasticity tensors; usage: Distances and closest tensors.

TensND.tensor_function Function
julia
tensor_function(f, t::AbstractTens) → AbstractTens

The function f of the symmetric tensor t: the tensor that has the eigenprojectors of t and the eigenvalues ,

At order 4 (with the minor and the major symmetries) the eigenvalues are those of the Kelvin-Mandel matrix; at order 2 those of the tensor. log, exp, sqrt, inv, atan or any scalar function may be given: tensor_function(log, ℂ) is the logarithm of a positive-definite stiffness.

A structured tensor is a combination of orthogonal projectors, so that f is taken on its coefficients and the class is kept, with symbolic coefficients too:         for a TensISO, the three coefficients of a TensCubic, the block of the two coupled projectors and the two shear coefficients of a TensTI. true

julia> get_array(tensor_function(sqrt, Tens(get_array(ℂ))) ⊡ tensor_function(sqrt, Tens(get_array(ℂ)))) ≈ get_array(ℂ)

TensND.closest_tensor Function
julia
closest_tensor(A, class, [axis or frame]; distance = EuclideanDistance()) → (B, d)

The tensor B of the symmetry class class closest to the symmetric tensor A in the sense of distance, and that distance d. The class is :ISO, :TI with its axis, :ORTHO or :CUBIC with its frame, as in project, whose result this is for the Euclidean distance.

For a distance built on a function (LogEuclideanDistance, FunctionEuclideanDistance), a symmetry class with a given axis or frame is a linear space that maps into itself, so that the closest tensor is

with the Euclidean projection on the class. For the closest isotropic tensor this gives    and    (Morin et al., 2020). The closest tensor in the sense of the RiemannianDistance has no such form: it is computed by the method of Gauss and Newton on the logarithm of B, from the log-Euclidean one, for numbers only.

With a distance invariant under inversion, the tensor closest to a stiffness is the inverse of the one closest to its compliance.

The tensors are of any dimension, with the isotropic class; the classes with an axis or a frame are those of dimension 3.

Examples

julia
julia> ℂ = TensCubic(30.0, 8.0, 12.0, CanonicalBasis{3, Float64}());

julia> B, d = closest_tensor(ℂ, :ISO; distance = LogEuclideanDistance());

julia> get_data(B)[2] ≈ exp((2 * log(8.0) + 3 * log(12.0)) / 5)
true

julia> S, _ = closest_tensor(inv(ℂ), :ISO; distance = LogEuclideanDistance());

julia> all(get_data(inv(S)) .≈ get_data(B))
true

See also tensor_distance, project, best_fit_iso.

Exact rotation-group averages ​

A projection is a least-squares fit and drops whatever does not fit; a rotation-group average is exact and lossless on the invariant subspace. The two coincide only when the tensor already belongs to the class. Use the averages inside a computation — on a concentration or contribution tensor, which carries no major symmetry — and the fits only to report parameters.

TensND.isotropify Function
julia
isotropify(A) → TensISO

Closest isotropic tensor to A for the Frobenius distance, i.e. its orthogonal projection onto span(𝕁, 𝕂):

julia
ISO(𝕋) = (𝕋 ⊙ 𝕁) 𝕁 + (𝕋 ⊙ 𝕂)/(𝕂 ⊙ 𝕂) 𝕂

For an order-2 tensor this reduces to tr(A)/dim · 𝟏.

It does not commute with inversion

isotropify(inv(A)) ≠ inv(isotropify(A)): the Euclidean distance is not invariant under inversion, so projecting a stiffness and projecting the corresponding compliance give different isotropic materials. State which one was projected whenever a result is reported.

See also project, Isotropic tensors.

julia
isotropify(t::AbstractTens{4,3}) → TensISO{4}

Exact average of t over SO(3): α = T_iijj/3, β = (T_ijij − α)/5 → α𝕁 + β𝕂. Valid for minor-symmetric tensors with or without major symmetry (the isotropic subspace is {𝕁, 𝕂} in both cases), which is what distinguishes it from the AbstractArray method above — the latter is a Frobenius projection and the two coincide exactly on minor-symmetric input.

Exact SO(3) average of a 2nd-order tensor: (tr t / 3) 𝟏.

TensND.transverse_isotropify Function
julia
transverse_isotropify(t::AbstractTens{4,3}, n) → TensTI{4,T,8}

Exact average of t over all rotations about the axis n ((1/2π)∫ R_φ ⋆ t dφ), for a minor-symmetric t with or without major symmetry. The result lives in the full 8-dimensional axially-invariant space: the non-major-symmetric components (ℓ₃ ≠ ℓ₄) and the antisymmetric azimuthal couplings (ℓ₇, ℓ₈) are preserved — they are dropped by naive symmetric TI projections but present in e.g. averaged strain-concentration tensors.

TensND.ti8_params_from_mandel Function
julia
ti8_params_from_mandel(M::AbstractMatrix) → NTuple{8}

Coefficients (ℓ₁, …, ℓ₈) of the exact azimuthal average about e₃ of a minor-symmetric tensor given by its 6×6 Kelvin-Mandel matrix (Tensors.jl index order 11, 22, 33, 23, 13, 12). Orthogonal projection onto the commutant algebra; TensND Walpole convention (ℓ₃ ↔ the C₃₃₁₁ side, ℓ₄ ↔ the C₁₁₃₃ side).

Two distinct uses, and the difference matters:

  • as an average, on a matrix that is not axially invariant — this is what transverse_isotropify calls;

  • as an exact read-off, on a matrix already known to be axially invariant about e₃, where the projection is the identity and the eight coefficients are simply recovered. This is the non-major-symmetric counterpart of ti_params_from_mandel, which projects onto the 5-coefficient major-symmetric span and would silently discard ℓ₃ ≠ ℓ₄, ℓ₇ and ℓ₈ — precisely the content a concentration tensor carries.

TensND.iso_average_mandel Function
julia
iso_average_mandel(M::AbstractMatrix) → (α, β)

Exact isotropic average of the minor-symmetric tensor whose Kelvin-Mandel matrix is the n×n matrix M, in any dimension d, read from the size n = d(d+1)/2 (mandel_dimension): the orthogonal projection of M onto the matrices of 𝕁 and 𝕂,

julia
α = (1/d) Σ_{i,j≤d} M[i,j],    β = (tr M − α)/(n − 1),

since the matrix of 𝕁 is 𝐢 𝐢ᵀ/d, 𝐢 the Kelvin-Mandel vector of 𝟏, and 𝕂 is the projector of trace n − 1. Returns the (α, β) coefficients of α𝕁 + β𝕂 (TensISO{d}(α, β)): α = (1/3)Σ_{i,j≤3} M[i,j], β = (tr M − α)/5 in space.

It is the average over the rotations of dimension d ≥ 3, with or without major symmetry. In the plane, the rotations alone also keep a skew coupling of the two deviatoric components, which vanishes for a major-symmetric M; (α, β) is then the average over the rotations and the reflections. A matrix of size 1×1 (dimension 1) has no deviatoric part, and β is not defined.
