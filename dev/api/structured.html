Structured tensors — isotropic ​

Compact storage for isotropic tensors, in arbitrary dimension. Theory: Isotropic tensors; usage: Structured tensors.

TensND.TensISO Type
julia
TensISO{order,dim,T,N}

Isotropic tensor stored as N scalars instead of dim^order components, in arbitrary dimension.

ParametrizationRoleInvariance groupStored coefficients
TensISO{2, dim, T, 1}2nd-order isotropicO(dim)data = (λ,): λ 𝟏
TensISO{4, dim, T, 2}4th-order isotropicO(dim)data = (α, β): α 𝕁 + β 𝕂

with 𝕁 = (𝟏⊗𝟏)/dim the spherical projector and 𝕂 = 𝕀 − 𝕁 the deviatoric one. In 3-D elasticity α = 3k and β = 2μ.

Because 𝕁 and 𝕂 are complementary orthogonal projectors, the algebra is that of a pair of independent scalars: products multiply them termwise and inverses take their reciprocals, both in closed form and both staying in the type; an isotropic tensor is its own transpose and major-symmetric. It has no orientation, so it needs none stored. As TensTI and TensOrtho, the type carries its order and number of coefficients.

Constructors

TensISO{dim}(λ) and TensISO{dim}(α, β), plus the named ones tens_Id2, tens_Id4, tens_J4, tens_K4, and iso_projectors.

Examples

julia
julia> ℂ = TensISO{3}(3 * 20.0, 2 * 8.0);

julia> get_data(inv(ℂ))
(0.016666666666666666, 0.0625)

julia> typeof(inv(ℂ)) === typeof(ℂ)
true

See also Isotropic tensors, Structured tensors.

TensND.iso_projectors Function
julia
iso_projectors(::Val{dim} = Val(3), ::Val{T} = Val(Sym))

Return the three fourth-order isotropic tensors (𝕀, 𝕁, 𝕂) — the symmetric identity, spherical projector, and deviatoric projector. Any isotropic 4th-order tensor can be written as α·𝕁 + β·𝕂.

Examples

julia
julia> 𝕀, 𝕁, 𝕂 = iso_projectors();

julia> 𝕁 + 𝕂 == 𝕀
true

See also tens_Id4, tens_J4, tens_K4.

The small matrices whose products and inverses are those of the tensors of a class; usage on Blocks: a class as a sum of small matrices.

julia
symmetry_blocks(A, M::AbstractMatrix) -> Tuple of SMatrix

The blocks, in the class and frame of A, of the matrix M: a   Kelvin-Mandel matrix at order 4, a   matrix of components at order 2, in the canonical basis. Each block is read on its first copy in ; when M belongs to the class, symmetry_matrix(A, symmetry_blocks(A, M)) ≈ M, and the blocks are those of the tensor M stands for.

TensND.from_symmetry_blocks Function
julia
from_symmetry_blocks(A, blocks) -> AbstractTens

The tensor of the class and frame of A whose blocks are blocks: the inverse of symmetry_blocks. A product of two symmetric tensors of a class need not be symmetric, so a transversely isotropic or orthotropic result takes the general shape of its class (six Walpole coefficients, twelve orthotropic constants).

julia
symmetry_layout(A) -> Tuple

For each block of symmetry_blocks(A), the index sets of its copies on the diagonal of , = symmetry_basis(A): the isotropic shear modulus sits on five, the transverse shear on two, and so on.

TensND.symmetry_matrix Function
julia
symmetry_matrix(A, blocks) -> SMatrix

The matrix (Kelvin-Mandel at order 4, of components at order 2, in the canonical basis) of the member of the class and frame of A whose blocks are blocks: the inverse of symmetry_blocks(A, M) on the class.
