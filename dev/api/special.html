TensND.rotation_matrix Function
julia
rotation_matrix(θ, ϕ, ψ = 0)

The 3×3 rotation matrix of the Euler angles θ, ϕ, ψ (ZYZ: θ the inclination from , ϕ the azimuth, ψ the spin about the rotated axis). Its third column is the unit vector of inclination θ and azimuth ϕ. With a single angle, rotation_matrix(θ) is the 2D rotation.

Examples

julia
julia> cθ, cϕ, cψ, sθ, sϕ, sψ = symbols("cθ cϕ cψ sθ sϕ sψ", real = true) ;

julia> d = Dict(cos(θ) => cθ, cos(ϕ) => cϕ, cos(ψ) => cψ, sin(θ) => sθ, sin(ϕ) => sϕ, sin(ψ) => sψ) ;

julia> subs.(rotation_matrix(θ, ϕ, ψ),d...)

Random tensors and orientations ​

Manual: Random tensors. Theory: Uniform random rotations.

Base.rand Method
julia
rand([rng], class; definite = false, ...) -> AbstractTens
rand([rng], class, dims...) -> Array

A tensor of class with random coefficients and, for a class with a direction, a random orientation. class is the type of the tensor, given either by its class with the default shape and Float64 coefficients, or in full for another shape or element type:

classreturnsdirection (keyword)
TensISO{4, dim}, TensISO{2, dim}isotropicnone
TensTI{4} (N = 5), TensTI{4, T, N} (N = 5, 6, 8)transversely isotropicaxis = random_axis(rng, T), or frame
TensTI{2} (N = 2), TensTI{2, T, N} (N = 2, 3)transversely isotropicaxis = random_axis(rng, T), or frame
TensOrtho{4} (N = 9), TensOrtho{4, T, N} (N = 9, 12)orthotropicframe = random_basis(rng, T)
TensOrtho{2}, TensOrtho{2, T}orthotropicframe = random_basis(rng, T)
TensCubic, TensCubic{T}cubicframe = random_basis(rng, T)
Tens{order, dim}, Tens{order, dim, T} (order = 2, 4)genericnone: its law is invariant

Passing axis or frame fixes the direction and leaves only the coefficients random; a transversely isotropic tensor takes either, the axis being the third vector of the frame. Without a generator rng, Random.default_rng() is used; rand(class, n) draws an array of n tensors of the default law, as rand does for numbers; with keywords, an array is a comprehension, [rand(rng, class; definite = true) for _ in 1:n]. definite = true draws a positive definite tensor, for the shapes with the major symmetry (the default ones); the others refuse it. A generic tensor takes symmetry: Val(:major) (the default, minor and major symmetries, the class of elastic moduli), Val(:minor) or Val(:none) at order 4, Val(:symmetric) (the default) or Val(:none) at order 2.

The laws. The Kelvin–Mandel matrix of the tensor in its own frame has the block structure of its class. Each symmetric block is drawn from the Gaussian orthogonal ensemble, or, positive definite, with Haar eigenvectors and log-normal eigenvalues; each block without symmetry has independent standard normal entries; a scalar block is standard normal, or log-normal. Each law is invariant under the orthogonal changes of basis of its block, so that a generic tensor needs no random frame, its law being already invariant under rotations. See Random tensors.

Examples

julia
julia> using Random; rng = Xoshiro(1);

julia> ℂ = rand(rng, TensCubic; definite = true);   # a cubic crystal, random cube

julia> ℂ isa TensCubic && minimum(eigvals(Symmetric(Matrix(mandel(ℂ))))) > 0
true

julia> rand(rng, TensTI{4}; axis = (0.0, 0.0, 1.0)) isa TensTI{4, Float64, 5}
true
TensND.random_rotation Function
julia
random_rotation([rng], [T = Float64]) -> SMatrix{3, 3, T}

A rotation drawn from the Haar measure of SO(3): the uniform law on the rotations, which no orientation favors. It is the rotation of a unit quaternion drawn uniformly on the unit sphere of ℝ⁴, the normalization of four independent standard normal numbers (see Random rotations).

Drawing the three Euler angles uniformly does not give this law: the axis e₃ would then fall near the poles as often as near the equator.

See also random_axis, random_basis, rand.

TensND.random_axis Function
julia
random_axis([rng], [T = Float64]) -> NTuple{3, T}

A unit vector drawn uniformly on the unit sphere: three independent standard normal numbers, normalized. It is the axis R⋅e₃ of a random_rotation R, and the law of the axis of a random transversely isotropic tensor.

TensND.random_basis Function
julia
random_basis([rng], [T = Float64]) -> RotatedBasis{3, T}

The orthonormal basis of the columns of a random_rotation: a frame of uniformly random orientation, the law of the frame of a random orthotropic or cubic tensor.
