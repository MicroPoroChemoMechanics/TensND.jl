References

Works cited in this documentation. Every entry has been checked against Crossref — DOI, authors, journal, volume, issue, pages and year — or, for the books without a DOI, against the publisher record.

The documentation follows one rule throughout: every formula is either accompanied by a citation, derived explicitly on the page from expressions that are, or read off the implementation with the source file named. Where a convention differs between references, the competing conventions are named and the one implemented by TensND is stated.
