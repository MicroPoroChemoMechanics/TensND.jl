The isotropic tensor closest to a measured stiffness ​

See also

Theory: Distances between elasticity tensors

Manual: Distances and closest tensors

A stiffness measured on a material has 21 constants, and a first computation often wants two: a bulk and a shear modulus. Which isotropic tensor is the closest to the measured one depends on what "close" means. This tutorial takes a stiffness identified by ultrasonic measurements (François et al., 1998) and compares the isotropic tensors closest to it for the distances of the package, as Morin, Gilormini and Derrien do for the distances they introduce.

julia
using TensND
using LinearAlgebra
using JSON
using Printf
using Plots
gr()

The measured stiffness ​

The tensor is given by its Kelvin-Mandel matrix, in GPa. It is stored with its source under data/literature.

julia
data = JSON.parsefile(joinpath(pkgdir(TensND), "data", "literature", "francoisIJSS1998.json"))
components = ("11", "22", "33", "23", "13", "12")
rows = data["tables"]["kelvin_mandel"]
ℂ = from_mandel(Float64[row[c] for row in rows, c in components])
round.(mandel(ℂ); digits = 1)

It is positive-definite, and far from isotropic: its relative Euclidean distance to its isotropic projection is

julia
eigvals(Symmetric(Matrix(mandel(ℂ)))), last(project(ℂ, Val(:ISO)))
([46.967991149461135, 78.46089564255912, 246.79662808539248, 282.56669480966895, 311.9368291963351, 512.2709611165834], 0.3454919236683317)

Two Euclidean answers ​

The Euclidean projection of the stiffness and that of the compliance are two isotropic materials. Their bulk moduli are close; their shear moduli are not.

julia
𝕊 = inv(ℂ)
primal = first(closest_tensor(ℂ, :ISO))
dual = inv(first(closest_tensor(𝕊, :ISO)))
bulk_shear(primal), bulk_shear(dual)
((170.11111111111111, 96.86666666666667), (169.33046488754968, 55.78298041088888))

These are the values published for this tensor (Moakher and Norris, 2006):

julia
published(name) = data["quantities"][name]["value"]
(published("k_primal"), published("mu_primal")), (published("k_dual"), published("mu_dual"))
((170.11, 96.87), (169.33, 55.81))

The dual shear modulus computed here, 55.78 GPa, differs from the published one in its fourth digit; the three other moduli agree to the digits printed. The first tensor is the mean of Voigt, the second that of Reuss: an average of the stiffness over the orientations, and of the compliance.

Distances that do not choose ​

With a distance invariant under inversion the closest tensor is the same whether the stiffness or the compliance is given. The log-Euclidean and the Riemannian distances have no parameter:

julia
for (name, distance) in ("log-Euclidean" => LogEuclideanDistance(), "Riemannian" => RiemannianDistance())
    B, d = closest_tensor(ℂ, :ISO; distance)
    S, _ = closest_tensor(𝕊, :ISO; distance)
    k, μ = bulk_shear(B)
    kₛ, μₛ = bulk_shear(inv(S))
    @printf "%-14s  k = %.2f GPa  μ = %.2f GPa   from the compliance: k = %.2f  μ = %.2f   distance %.4f\n" name k μ kₛ μₛ d
end
log-Euclidean   k = 169.84 GPa  μ = 75.90 GPa   from the compliance: k = 169.84  μ = 75.90   distance 1.7221
Riemannian      k = 169.69 GPa  μ = 75.91 GPa   from the compliance: k = 169.69  μ = 75.91   distance 1.7224

Both fall between the two Euclidean answers, and they differ from each other, the tensor not commuting with the isotropic ones.

The effect of a gauge ​

The arctan- and the power-Euclidean distances compare dimensionless tensors, divided by a gauge . Their closest isotropic tensor moves with it:

julia
gauges = 10 .^ range(0, 4; length = 61)
families = [
    "arctan" => E₀ -> ArctanEuclideanDistance(E₀), "power, n = 1/2" => E₀ -> PowerEuclideanDistance(1 / 2, E₀),
    "power, n = 1" => E₀ -> PowerEuclideanDistance(1, E₀), "power, n = 2" => E₀ -> PowerEuclideanDistance(2, E₀),
]
moduli = Dict(name => [bulk_shear(first(closest_tensor(ℂ, :ISO; distance = family(E₀)))) for E₀ in gauges] for (name, family) in families)
kₗ, μₗ = bulk_shear(first(closest_tensor(ℂ, :ISO; distance = LogEuclideanDistance())))
panels = map((1, 2), ("k (GPa)", "μ (GPa)"), (kₗ, μₗ), (bulk_shear(primal), bulk_shear(dual))) do i, label, logarithmic, _
    panel = plot(; xscale = :log10, xlabel = "gauge E₀ (GPa)", ylabel = label, legend = i == 2 ? :outerright : false)
    for (name, _) in families
        plot!(panel, gauges, getindex.(moduli[name], i); lw = 2, label = name)
    end
    hline!(panel, [logarithmic]; color = :black, label = "log-Euclidean")
    hline!(panel, [bulk_shear(primal)[i], bulk_shear(dual)[i]]; color = :gray, ls = :dash, label = i == 2 ? "Euclidean (stiffness, compliance)" : "")
    panel
end
plot(panels...; layout = grid(1, 2; widths = [0.4, 0.6]), size = (980, 360), left_margin = 4Plots.mm, bottom_margin = 4Plots.mm)

For a small gauge the dimensionless stiffness is large,   is close to , and the power-Euclidean distance of exponent 1 is the Euclidean distance on the stiffnesses; for a large gauge it is that on the compliances. The arctan-Euclidean distance has the same two limits, in the other order:

julia
limits(family) = (bulk_shear(first(closest_tensor(ℂ, :ISO; distance = family(1.0e-4)))), bulk_shear(first(closest_tensor(ℂ, :ISO; distance = family(1.0e7)))))
limits(E₀ -> PowerEuclideanDistance(1, E₀)), limits(E₀ -> ArctanEuclideanDistance(E₀))
(((170.11111111111114, 96.86666666664772), (169.33046329844123, 55.78298441832885)), ((169.33046456045676, 55.78298041667199), (170.11111111040722, 96.86666665564587)))

The closest isotropic material then depends on a modulus chosen freely. For this reason Morin et al. (2020) retain, among the distances built on a function, the log-Euclidean one, which no gauge enters.

Other symmetry classes ​

The same function gives the closest tensor of the other classes, with their axis or their frame. The distances to the classes are nested as the classes are:

julia
frame = CanonicalBasis{3, Float64}()
for (name, distance) in ("Euclidean" => EuclideanDistance(), "log-Euclidean" => LogEuclideanDistance(), "Riemannian" => RiemannianDistance())
    d = (
        last(closest_tensor(ℂ, :ORTHO, frame; distance)), last(closest_tensor(ℂ, :CUBIC, frame; distance)),
        last(closest_tensor(ℂ, :TI, [0.0, 0.0, 1.0]; distance)), last(closest_tensor(ℂ, :ISO; distance)),
    )
    @printf "%-14s  orthotropic %.4f   cubic %.4f   transversely isotropic %.4f   isotropic %.4f\n" name d...
end
Euclidean       orthotropic 180.0048   cubic 181.3590   transversely isotropic 211.7032   isotropic 246.4500
log-Euclidean   orthotropic 1.2343   cubic 1.2674   transversely isotropic 1.4517   isotropic 1.7221
Riemannian      orthotropic 1.2799   cubic 1.3174   transversely isotropic 1.4864   isotropic 1.7224

The distances of one line are in the unit of that line: GPa for the Euclidean one, none for the two others.
