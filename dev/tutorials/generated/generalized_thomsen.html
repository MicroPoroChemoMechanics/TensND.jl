Weak anisotropy of any symmetry ​

See also

Theory: Plane waves · Weak anisotropy of any symmetry · Thomsen's parameters

Manual: Plane waves

Tutorials: Thomsen's parameters and weak anisotropy · Stress-induced anisotropy

Thomsen's three parameters describe a transversely isotropic medium. A rock measured in every direction may have no symmetry at all: its stiffness then has 21 constants. To first order in the deviation from isotropy, the velocities of such a medium depend on combinations of these constants that generalize Thomsen's (Mensch and Rasolofosaon, 1997). This tutorial takes two triclinic rocks, a limestone and a sandstone, and compares their exact velocities with the first-order ones in every direction.

julia
using TensND
using LinearAlgebra
using JSON
using Printf
using Plots
using SymPyPythonCall: symbols
gr()

Two triclinic rocks ​

Mensch and Rasolofosaon (1997) list in their Appendix B the stiffness matrices, in the two-index notation (pairs 11, 22, 33, 23, 13, 12) and in GPa, of a water-saturated Lavoux limestone and of a dry Vosges sandstone, with their densities in kg/m³. They are stored with their source under data/literature; stiffness_from_voigt turns a matrix into the tensor .

julia
data = JSON.parsefile(joinpath(pkgdir(TensND), "data", "literature", "menschGJI1997.json"))
voigt(key) = Float64[row[c] for row in data["tables"][key], c in ("1", "2", "3", "4", "5", "6")]
density(key) = data["quantities"][key]["value"] / 1000                  # g/cm³: GPa with km/s
rocks = [
    (name = "Lavoux limestone", ℂ = stiffness_from_voigt(voigt("lavoux_stiffness")), ρ = density("lavoux_density")),
    (name = "Vosges sandstone", ℂ = stiffness_from_voigt(voigt("vosges_stiffness")), ρ = density("vosges_density")),
]
voigt("vosges_stiffness")                       ## the matrix of the sandstone, as printed

The generalized parameters ​

Measured from the vertical waves (  for P, and for the two S waves), seventeen dimensionless numbers fix the first-order velocities: , , , , play the roles of Thomsen's and in the three coordinate planes, and the six vanish with the orthotropic symmetry, and measure the shear anisotropy (Weak anisotropy of any symmetry).

for r in rocks

The parameters and the P wave with symbols ​

The parameters are ratios of the components , and they take symbols. A monoclinic stiffness whose mirror is the plane normal to has thirteen components; of the parameters, , and survive next to those of orthotropy:

julia
C₁₁, C₁₂, C₁₃, C₁₆, C₂₂, C₂₃, C₂₆, C₃₃, C₃₆, C₄₄, C₄₅, C₅₅, C₆₆ = symbols("C_11 C_12 C_13 C_16 C_22 C_23 C_26 C_33 C_36 C_44 C_45 C_55 C_66", real = true)
o = zero(C₁₁)
monoclinic = stiffness_from_voigt(
    [
        C₁₁ C₁₂ C₁₃ o o C₁₆
        C₁₂ C₂₂ C₂₃ o o C₂₆
        C₁₃ C₂₃ C₃₃ o o C₃₆
        o o o C₄₄ C₄₅ o
        o o o C₄₅ C₅₅ o
        C₁₆ C₂₆ C₃₆ o o C₆₆
    ]
)
gₛ = map(tsimplify, generalized_thomsen_parameters(monoclinic))
(εx = (C_22 - C_33)/(2*C_33), εy = (C_11 - C_33)/(2*C_33), δx = (C_23 - C_33 + 2*C_44)/C_33, δy = (C_13 - C_33 + 2*C_55)/C_33, δz = (C_12 - C_33 + 2*C_66)/C_33, χx = 0, χy = 0, χz = (C_36 + 2*C_45)/C_33, ε15 = 0, ε16 = C_16/C_33, ε24 = 0, ε26 = C_26/C_33, ε34 = 0, ε35 = 0, γx = (C_44 - C_55)/(2*C_55), γy = (-C_44 + C_66)/(2*C_44), γz = (-C_44 + C_55)/(2*C_44))

To first order the modulus of the P wave along a unit is the quartic form of Weak anisotropy of any symmetry,    , with

julia
function quartic(g, (n₁, n₂, n₃))
    return 2 * (g.εy * n₁^4 + g.εx * n₂^4 + g.δz * n₁^2 * n₂^2 + g.δy * n₁^2 * n₃^2 + g.δx * n₂^2 * n₃^2) +
        4 * (g.ε15 * n₁^3 * n₃ + g.ε16 * n₁^3 * n₂ + g.ε24 * n₂^3 * n₃ + g.ε26 * n₂^3 * n₁ + g.ε34 * n₃^3 * n₂ + g.ε35 * n₃^3 * n₁) +
        4 * (g.χx * n₁^2 * n₂ * n₃ + g.χy * n₁ * n₂^2 * n₃ + g.χz * n₁ * n₂ * n₃^2)
end

weak_plane_waves normalizes its direction: for of any length ,     , being homogeneous of degree four. Along a direction of three symbolic components the difference reduces to zero:

julia
n₁, n₂, n₃ = symbols("n_1 n_2 n_3", real = true)
ρₛ = symbols("ρ", positive = true)
ρV² = ρₛ * weak_plane_waves(monoclinic, ρₛ, [n₁, n₂, n₃]).qP[1]^2
r² = n₁^2 + n₂^2 + n₃^2
tsimplify(ρV² * r²^2 - C₃₃ * (r²^2 + quartic(gₛ, (n₁, n₂, n₃))))

Exact and first-order velocities ​

plane_waves solves the Christoffel problem exactly and sorts the three waves by decreasing velocity (qP, qS1, qS2); weak_plane_waves gives them to first order, the P modulus being    and the two S moduli the eigenvalues of restricted to the plane normal to . A direction is given by its angle to and its azimuth (direction_from_angles).

julia
exact_velocities(r, n) = plane_waves(r.ℂ, r.ρ, n).velocity
weak_velocities(r, n) = collect(map(first, values(weak_plane_waves(r.ℂ, r.ρ, n))))

Along the meridian   (the plane of and ) and around the vertical axis in the horizontal plane  :

julia
θs = range(0, π; length = 121)
ϕs = range(0, 2π; length = 121)
function velocity_panel(r, angles, direction, xlabel)
    V = [exact_velocities(r, direction(a))[k] for a in angles, k in 1:3]
    W = [weak_velocities(r, direction(a))[k] for a in angles, k in 1:3]
    p = plot(; title = r.name, titlefontsize = 10, xlabel, ylabel = "phase velocity (km/s)", xticks = 0:45:360, legend = :right)
    plot!(p, rad2deg.(angles), V; lw = 2, color = [1 2 3], label = ["qP" "qS1" "qS2"])
    plot!(p, rad2deg.(angles), W; lw = 2, ls = :dash, color = [1 2 3], label = ["first order" "" ""])
    return p
end
panels = [
    velocity_panel(r, a, d, x) for r in rocks
        for (a, d, x) in ((θs, θ -> direction_from_angles(θ, 0.0), "θ (°), ϕ = 0"), (ϕs, ϕ -> direction_from_angles(π / 2, ϕ), "ϕ (°), θ = 90°"))
]
plot(panels...; layout = (2, 2), size = (980, 680), left_margin = 4Plots.mm, bottom_margin = 4Plots.mm)

The error in every direction ​

A wave travels at the same velocity along and , so that the upper hemisphere suffices. The relative error   of each wave, on a grid of directions:

julia
θ_grid = range(0, π / 2; length = 46)
ϕ_grid = range(0, 2π; length = 91)
relative_error(r, n) = weak_velocities(r, n) ./ exact_velocities(r, n) .- 1
errors = [[relative_error(r, direction_from_angles(θ, ϕ)) for θ in θ_grid, ϕ in ϕ_grid] for r in rocks]
@printf "%-18s %9s %9s %9s\n" "largest |error|" "qP" "qS1" "qS2"
for (r, E) in zip(rocks, errors)
    @printf "%-18s %8.2f%% %8.2f%% %8.2f%%\n" r.name (100 * maximum(e -> abs(e[k]), E) for k in 1:3)...
end

Shear-wave splitting ​

The two shear waves of a direction travel at different velocities: a shear pulse splits into a fast and a slow one. shear_splitting gives the relative difference  , the polarization of the fast wave and the delay per unit length of path (Shear-wave splitting):

julia
shear_splitting(rocks[2].ℂ, rocks[2].ρ, [0.0, 0.0, 1.0])
(splitting = 0.075674121220587, fast = [0.9981145308083227, 0.0, 0.06137901424169147], delay = 0.04832745952439188)

Its map, in percent; it vanishes in the directions where the two shear waves have the same velocity (acoustic axes):

julia
maps = [
    heatmap(
        rad2deg.(ϕ_grid), rad2deg.(θ_grid), [100 * shear_splitting(r.ℂ, r.ρ, direction_from_angles(θ, ϕ)).splitting for θ in θ_grid, ϕ in ϕ_grid];
        title = r.name, titlefontsize = 10, xlabel = "ϕ (°)", ylabel = "θ (°)", xticks = 0:90:360, color = :viridis
    ) for r in rocks
]
plot(maps...; layout = (1, 2), size = (980, 340), left_margin = 4Plots.mm, bottom_margin = 4Plots.mm)

A transversely isotropic case ​

For a transversely isotropic medium of axis the generalized parameters reduce to Thomsen's:   ,  , and   equals to first order (Weak anisotropy of any symmetry). The Mesaverde sandstone of the same appendix, matrix (B1), checks it; its five independent entries give the TensTI that thomsen_parameters reads:

julia
C = voigt("mesaverde_sandstone_stiffness")
ρ = density("mesaverde_sandstone_density")
ℂ = ti_from_constants(C[1, 1], C[1, 2], C[1, 3], C[3, 3], C[4, 4], [0.0, 0.0, 1.0]; form = :components, role = :stiffness)
g = generalized_thomsen_parameters(stiffness_from_voigt(C))
t = thomsen_parameters(ℂ, ρ)
(εx = g.εx, εy = g.εy, ε = t.ε), (δx = g.δx, δy = g.δy, δ = t.δ), (γy = g.γy, γ = t.γ)
((εx = 0.053347280334728055, εy = 0.053347280334728055, ε = 0.053347280334728055), (δx = 0.14225941422594138, δy = 0.14225941422594138, δ = 0.15766329984276323), (γy = 0.0670731707317074, γ = 0.0670731707317074))
