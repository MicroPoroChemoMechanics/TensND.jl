Differential operators, symbolically

The five operators of Curvilinear differential calculus — GRAD, SYMGRAD, DIV, LAPLACE, HESS — applied in polar, cylindrical and spherical coordinates, with exact SymPy derivatives. The results are closed-form expressions, valid everywhere, not values at a point.

The definitions, once:

\[\mathrm{GRAD}(t)=\sum_i\partial_i t\otimes\underline{a}^i, \qquad \mathrm{SYMGRAD}(t)=\sum_i\partial_i t\stackrel{s}{\otimes}\underline{a}^i, \qquad \mathrm{DIV}(t)=\sum_i\partial_i t\cdot\underline{a}^i .\]

using TensND
using LinearAlgebra
using SymPy

Setting a default coordinate system

@set_coorsys makes a system the default, so the operators can be called with one argument.

Polar = coorsys_polar()
r, θ = getcoords(Polar)
𝐞ʳ, 𝐞ᶿ = unitvec(Polar)
@set_coorsys Polar
CoorSystemSym{2, Sym{PyCall.PyObject}, TensND.TensRotated{1, 2, Sym{PyCall.PyObject}, Tensors.Vec{2, Sym{PyCall.PyObject}}}, RotatedBasis{2, Sym{PyCall.PyObject}}, OrthogonalBasis{2, Sym{PyCall.PyObject}}}(TensND.ChartCore{2, Sym{PyCall.PyObject}, TensND.TensRotated{1, 2, Sym{PyCall.PyObject}, Tensors.Vec{2, Sym{PyCall.PyObject}}}, RotatedBasis{2, Sym{PyCall.PyObject}}, OrthogonalBasis{2, Sym{PyCall.PyObject}}}(Sym{PyCall.PyObject}[r, 0], (r, θ), Sym{PyCall.PyObject}[cos(θ) -sin(θ); sin(θ) cos(θ)], Sym{PyCall.PyObject}[cos(θ) -r*sin(θ); sin(θ) r*cos(θ)], (Sym{PyCall.PyObject}[1, 0], Sym{PyCall.PyObject}[0, r]), (1, r), (Sym{PyCall.PyObject}[1, 0], Sym{PyCall.PyObject}[0, 1/r]), (Sym{PyCall.PyObject}[1, 0], Sym{PyCall.PyObject}[0, 1]), Sym{PyCall.PyObject}[0 0; 0 -r;;; 0 1/r; 1/r 0], (), (), Dict{Any, Any}(), Dict{Any, Any}(), Dict{Any, Any}()))

The polar Laplacian

Applied to an arbitrary function, LAPLACE reproduces the textbook operator $\partial_{rr}f+\tfrac{1}{r}\partial_r f+\tfrac{1}{r^2}\partial_{\theta\theta}f$:

f = SymFunction("f", real = true)(r, θ)
LAPLACE(f)

\[\frac{\partial^{2}}{\partial r^{2}} f{\left(r,θ \right)} + \frac{\frac{\partial}{\partial r} f{\left(r,θ \right)}}{r} + \frac{\frac{\partial^{2}}{\partial θ^{2}} f{\left(r,θ \right)}}{r^{2}}\]

Harmonic functions in the plane are $r^n\cos n\theta$ and $r^n\sin n\theta$; their Laplacian vanishes identically for symbolic $n$:

n = symbols("n", integer = true)
simplify(LAPLACE(r^n * cos(n * θ)))

\[0\]

while a mismatched pair of exponents does not vanish, and the residual is the familiar $(n^2-m^2)r^{n-2}$:

m = symbols("m", integer = true)
simplify(LAPLACE(r^n * sin(m * θ)) / (r^(n - 2) * sin(m * θ)))

\[- m^{2} + n^{2}\]

The Hessian

$\mathrm{HESS}=\mathrm{GRAD}\circ\mathrm{GRAD}$, and its trace is the Laplacian:

H = simplify(HESS(r^n))

\[\left[\begin{smallmatrix}\frac{n^{2} r^{n}}{r^{2}} - \frac{n r^{n}}{r^{2}} & 0\\0 & \frac{n r^{n}}{r^{2}}\end{smallmatrix}\right]\]

simplify(tr(H) - LAPLACE(r^n))

\[0\]

Cylindrical coordinates: an axisymmetric strain tensor

SYMGRAD applied to a displacement field is directly the linearized strain tensor. For an axisymmetric field $\underline{\xi}(r,z)=\xi^r\underline{e}^r +\xi^z\underline{e}^z$, the hoop strain $\varepsilon_{\theta\theta}=\xi^r/r$ appears from the Christoffel terms alone — there is no $\theta$ derivative anywhere in the field.

Cylindrical = coorsys_cylindrical()
rc, θc, zc = getcoords(Cylindrical)
𝐞ʳᶜ, 𝐞ᶿᶜ, 𝐞ᶻᶜ = unitvec(Cylindrical)
@set_coorsys Cylindrical

ξʳ = SymFunction("ξʳ", real = true)(rc, zc)
ξᶻ = SymFunction("ξᶻ", real = true)(rc, zc)
𝛏 = ξʳ * 𝐞ʳᶜ + ξᶻ * 𝐞ᶻᶜ

𝛆 = tsimplify(SYMGRAD(𝛏))

\[\left[\begin{smallmatrix}\frac{\partial}{\partial r} \operatorname{ξʳ}{\left(r,z \right)} & 0 & \frac{\frac{\partial}{\partial z} \operatorname{ξʳ}{\left(r,z \right)}}{2} + \frac{\frac{\partial}{\partial r} \operatorname{ξᶻ}{\left(r,z \right)}}{2}\\0 & \frac{\operatorname{ξʳ}{\left(r,z \right)}}{r} & 0\\\frac{\frac{\partial}{\partial z} \operatorname{ξʳ}{\left(r,z \right)}}{2} + \frac{\frac{\partial}{\partial r} \operatorname{ξᶻ}{\left(r,z \right)}}{2} & 0 & \frac{\partial}{\partial z} \operatorname{ξᶻ}{\left(r,z \right)}\end{smallmatrix}\right]\]

Read off the hoop component:

get_array(𝛆)[2, 2]

\[\frac{\operatorname{ξʳ}{\left(r,z \right)}}{r}\]

Spherical coordinates

Recall the unusual ordering $(\theta,\varphi,r)$, chosen so that $\theta=\varphi=0$ gives the canonical basis in the canonical order.

Spherical = coorsys_spherical()
θs, ϕs, rs = getcoords(Spherical)
𝐞ᶿ, 𝐞ᵠ, 𝐞ʳˢ = unitvec(Spherical)
@set_coorsys Spherical

getcoords(Spherical), Lame(Spherical)
((θ, ϕ, r), (r, r*sin(θ), 1))

The gradient of the radius is the radial unit vector, and the divergence of that vector is $2/r$:

tsimplify(GRAD(rs)), tsimplify(DIV(𝐞ʳˢ))
(Sym{PyCall.PyObject}[0, 0, 1], 2/r)

The gradient of $\underline{e}^r$ is the transverse projector divided by $r$ — the relation that makes a sphere's curvature $-1/r$, see Submanifolds:

tsimplify(GRAD(𝐞ʳˢ) - (𝐞ᶿ ⊗ 𝐞ᶿ + 𝐞ᵠ ⊗ 𝐞ᵠ) / rs)

\[\left[\begin{smallmatrix}0 & 0 & 0\\0 & 0 & 0\\0 & 0 & 0\end{smallmatrix}\right]\]

$1/r$ is the kernel of the three-dimensional Laplace equation:

tsimplify(LAPLACE(1 / rs))

\[0\]

Radial equilibrium of a spherical stress state

A diagonal stress field in the spherical frame. Its divergence gives the equilibrium equation of a spherically symmetric problem — the $2(\sigma^{rr} -\sigma^{\theta\theta})/r$ term coming entirely from the connection.

σʳʳ = SymFunction("σʳʳ", real = true)(rs)
σᶿᶿ = SymFunction("σᶿᶿ", real = true)(rs)
σᵠᵠ = SymFunction("σᵠᵠ", real = true)(rs)
𝛔 = σʳʳ * 𝐞ʳˢ ⊗ 𝐞ʳˢ + σᶿᶿ * 𝐞ᶿ ⊗ 𝐞ᶿ + σᵠᵠ * 𝐞ᵠ ⊗ 𝐞ᵠ

simplify(DIV(𝛔))

\[\left[\begin{smallmatrix}r \left(- \frac{\operatorname{σᵠᵠ}{\left(r \right)} \sin{\left(2 θ \right)}}{2 r^{2} \sin^{2}{\left(θ \right)}} + \frac{\operatorname{σᶿᶿ}{\left(r \right)}}{r^{2} \tan{\left(θ \right)}}\right)\\0\\\frac{d}{d r} \operatorname{σʳʳ}{\left(r \right)} + \frac{2 \operatorname{σʳʳ}{\left(r \right)}}{r} - \frac{\operatorname{σᵠᵠ}{\left(r \right)}}{r} - \frac{\operatorname{σᶿᶿ}{\left(r \right)}}{r}\end{smallmatrix}\right]\]

Index placement is a convention

GRAD appends the derivative index on the right, so $(\nabla\underline{v})_{ij}=\partial_j v_i$, and DIV contracts the last index, $(\mathrm{DIV}\,\boldsymbol{\sigma})_i=\partial_j\sigma_{ij}$. In Cartesian coordinates, where all Christoffel symbols vanish, this is easy to read off:

Cartesian = coorsys_cartesian()
X = getcoords(Cartesian)
E = unitvec(Cartesian)
@set_coorsys Cartesian

v = sum(SymFunction("v$i", real = true)(X...) * E[i] for i in 1:3)
Gv = get_array(GRAD(v))

(Gv[1, 2], diff(SymFunction("v1", real = true)(X...), X[2]))
(Derivative(v1(x, y, z), y), Derivative(v1(x, y, z), y))

The $(1,2)$ entry is $\partial_y v_1$, not $\partial_x v_2$. A library using the opposite convention differs by a transpose.
