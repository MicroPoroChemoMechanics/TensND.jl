Changing the focal distance of spheroidal harmonics ​

See also

Theory: Changes of coordinates · Spheroidal harmonics and their re-expansion · Spheroidal coordinates

Manual: Charts and coordinate conversions · Spheroidal harmonics

Tutorials: Ellipsoidal coordinates · The spheroid in spheroidal coordinates

A field that is harmonic around a spheroid is a series of spheroidal harmonics of the system confocal with that spheroid. When a second spheroidal surface of the same axis is not confocal with the first one, a condition written on it needs the same field in the harmonics of its own system. This tutorial computes the harmonics of two coaxial systems, passes from one to the other, and measures where and how fast the series converge. The formulas are proved on Spheroidal harmonics and their re-expansion; they are those that Riccardi and Montheillet (1999) use for a spheroidal inclusion surrounded by a non-confocal spheroidal shell.

julia
using TensND
using LinearAlgebra
using Printf
using Plots

Interior harmonics: a finite sum ​

An interior harmonic is a polynomial of the Cartesian coordinates. In the other system it is a finite combination of the interior harmonics of degrees  ,

and interior_reexpansion returns the , the target chart first:

julia
L = interior_reexpansion(chart₂, chart₁, 5, 1)
3-element Vector{Float64}:
   7.59375
  36.91406250000001
 160.83984375

The identity holds at every point, inside the spheroids as well as outside:

julia
function interior_gap(to, from, n, m, x)
    lhs = interior_harmonics(from, n, m, cartesian_to_coords(from, x))[n + 1]
    rhs = sum(interior_reexpansion(to, from, n, m) .* interior_harmonics(to, n, m, cartesian_to_coords(to, x))[(n + 1):-2:(m + 1)])
    return abs(rhs / lhs - 1)
end
[interior_gap(chart₂, chart₁, 5, 1, y) for y in ([0.7, -0.4, 2.1], [0.1, 0.2, 0.3], [3.0, 1.0, -8.0])]

Exterior harmonics: a series ​

An exterior harmonic is a series of the exterior harmonics of degrees   of the other system,

whose coefficients exterior_reexpansion returns up to a given index:

julia
K = exterior_reexpansion(chart₂, chart₁, 2, 1, 6)
7-element Vector{Float64}:
  0.2962962962962963

  0.08067150042458686
  0.0120556656336263
 -0.02461370679820611
  0.0009364091855433844

The error of the partial sums is measured at the point above:

julia
function exterior_errors(to, from, n, m, x, imax)
    exact = exterior_harmonics(from, n, m, cartesian_to_coords(from, x))[n + 1]
    terms = exterior_reexpansion(to, from, n, m, imax) .*
        exterior_harmonics(to, n + 2imax, m, cartesian_to_coords(to, x))[(n + 1):2:end]
    return abs.(cumsum(terms) ./ exact .- 1)
end
errors = exterior_errors(chart₂, chart₁, 2, 1, x, 25)
@printf "terms    error\n"
for N in (1, 3, 5, 10, 15, 20)
    @printf "%5d    %.1e\n" N errors[N]
end

Where the series converges ​

The series converges outside the smallest spheroid of the target system that encloses the focal segment of the source system. reexpansion_bound returns it as a value of the radial coordinate of the target. From   to   the focal segment of the source is inside that of the target, and the series converges everywhere off the latter; the other way, it converges for  :

julia

(1.0, 1.5)

Prolate, oblate and spherical ​

The two systems may be prolate, oblate or spherical in any combination. An exterior harmonic of an oblate system (a disk-like inclusion) in the harmonics of a prolate one:

oblate = OblateSpheroidalChart(0.8)
y = [1.9, 0.6, 1.4]
reexpansion_bound(chart₁, oblate), cartesian_to_coords(chart₁, y)[3]
(1.2806248474865698, 2.575767467693301)
julia
